# 1.5 Enterprise Search (25 points)

## Server Search Points (13)
1. Search engine abstraction (Elasticsearch / Solr)
2. Document indexing pipeline
3. Full-text search with highlighting
4. Faceted search (modality, body part, status)
5. Synonym expansion (clinical terms)
6. Pinyin/Chinese search support
7. Fuzzy search (Levenshtein)
8. Search result ranking (relevance score)
9. Search query parsing
10. Index maintenance (rebuild/optimize)
11. Search monitoring dashboard
12. Search suggestion / auto-complete
13. Cross-index search (patients+exams+reports)

## Client Search Points (12)
1. Search client API wrapper
2. Search result types
3. Saved search / bookmark
4. Recent search history
5. Search analytics tracking
6. Search filter builder
7. Advanced search form (AND/OR/NOT)
8. Search result export (CSV/PDF)
9. Search result pagination
10. Search result sorting
11. Search result caching
12. Search error handling
