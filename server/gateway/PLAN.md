# 1.3 Cloud-Native Architecture – Gateway (40 points)

## Gateway Points (12)
1. API gateway route definitions
2. Rate limiter (token bucket)
3. Circuit breaker pattern
4. Load balancer (round-robin/least-connections)
5. Service discovery (static + dynamic)
6. API versioning (Accept header / URL)
7. Request/response transformation
8. API composition (aggregate multiple services)
9. Gateway health check
10. Gateway metrics
11. Gateway audit log
12. CORS and header management

## Deploy Points (14)
1. Dockerfile (multi-stage build)
2. docker-compose.yml (all services)
3. Kubernetes Deployment manifests
4. Kubernetes Service manifests
5. Kubernetes ConfigMap
6. Kubernetes Secret
7. Helm chart (Chart.yaml, values.yaml)
8. Helm deployment templates
9. Horizontal Pod Autoscaler
10. Ingress controller config
11. Health check probes (liveness/readiness)
12. Resource limits/requests
13. Init containers for DB migration
14. Pod anti-affinity for HA

## Middleware Points (14)
1. JWT authentication middleware
2. Role-based access control middleware
3. Audit logging middleware
4. Multi-tenant isolation middleware
5. Error handling middleware (global)
6. Request logging middleware
7. Response caching middleware
8. Compression middleware (gzip/brotli)
9. Security headers middleware (CSP, HSTS)
10. Metrics collection middleware (Prometheus)
11. Request ID tracing middleware
12. Timeout middleware
13. Request validation middleware (Zod)
14. IP whitelist middleware
