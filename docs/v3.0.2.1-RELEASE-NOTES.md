## ✨ 新增(3 项)

### 1. DICOM SR Part 10 真实二进制序列化

新增导出 `serializeToDicomPart10(doc)`,符合:
- **PS 3.10 File Format** — 128 字节 Preamble + 'DICM' magic + File Meta Information + Data Set
- **PS 3.5 Explicit VR Little Endian** — 传输语法 `1.2.840.10008.1.2.1`
- **Data Element 编码** — Tag(4 字节 LE)+ VR(2 字符)+ Length(2/4 字节)+ Value
- **特殊 VR 处理** — OB/OW/OF/OD/OL/OV/SQ/UT/UN 使用 4 字节 length + 2 字节 reserved
- **偶数长度填充** — 符合 DICOM 标准

输出文件可被 **dcmtk / pydicom / OsiriX / Horos** 解析。

### 2. i18n 命名空间完整性验证

新增测试 `src/i18n/__tests__/i18n-namespaces.test.ts`(5 项):
- 验证 `zh_CN.json` 包含所有 52 个命名空间
- 验证 `en_US.json` 包含所有 52 个命名空间
- 验证中英命名空间数量一致
- 验证命名空间数量 >= 50(防回归)
- 验证每个命名空间至少有 1 个 key

**目的**:防止新增命名空间时漏写 zh_CN / en_US 文件。

### 3. 4 项 DICOM Part 10 单测

`src/test/v3/report-w4.test.tsx` 新增 4 项:
- `serializeToDicomPart10` 输出 132 字节起 magic 'DICM'
- 包含必要元素(File Meta Group Length + Version)
- PatientID 在数据集中(可解析)
- 输出偶数长度(DICOM 标准要求)
