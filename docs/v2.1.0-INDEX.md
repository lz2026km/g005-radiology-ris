## 🚀 30 秒速览

G005 放射科 RIS 是一套**纯前端 + 模拟数据**的放射科信息系统,经过 9 个小版本(v0.15 - v0.23)+ 报告子系统 R0-R7 + AI 8 类 Prompt + 11 套 RADS 演进,现已具备**接近生产**的完整能力,主要组成:

- **89 个页面**(覆盖放射科全流程:工作列表 / 报告 / 影像 / AI / 危急值 / 协同 / 统计)
- **30+ 组件** / **15 个 Hooks** / **11 个 Services** / **30+ 工具**
- **27+ Mock 数据文件**(50 条报告 × 14 态 / 1247 词条 / 70+ 器官 / 11 套 RADS)
- **CA 数字签名 + Merkle 审计链** + **Yjs 协同编辑** + **Web Speech 语音** + **DeepSeek LLM**

**快速入口**:
- 新人:`01-ARCHITECTURE` → `03-REPORT-AI-KNOWLEDGE` → `04` 速查
- 架构师:`01-ARCHITECTURE` § 1-2 + `04` § 16 路线图

- 产品:`03-REPORT-AI-KNOWLEDGE` + `04` § 15

## 🆚 v0.15.0 → v2.1.0 升级要点

| 维度 | v0.15.0 | v2.1.0 |
|------|---------|--------|
| **版本日期** | 2026-05-04 | 2026-06-05 |
| **代码版本** | v0.15.0(冻结) | v0.23.1(实际)→ v2.0.0(包)→ v2.1.0(文档) |
| **文档形态** | 1 个文件 2217 行 | 4 分册 4000+ 行 + 索引 + 大纲 |
| **页面数** | "60+" | 89 |
| **数据 Mock** | 4 | 27+ |
| **报告状态机** | 6 态 | 14/15 态 |
| **AI 能力** | 描述级 | DeepSeek 客户端 + 8 类 Prompt + RADS 11 套 |
| **签名 / 审计** | 描述 | CA RSA-SHA256 + Merkle Tree |
| **协同** | 无 | Yjs CRDT + y-webrtc |
| **OpenAPI** | 无 | OpenAPI 3.0 + MSW |
| **DICOM 前端** | cornerstone 3.x 基础 | cornerstone 4.22 + 5 个 Pro 组件 + dcmjs + SR 导出 |

**升级重点**:从"基础前端 demo"演进为"准生产前端系统",但仍为纯前端 + Mock,生产环境需补后端(见分册 01 § 3.2 + 04 § 16.3)。
