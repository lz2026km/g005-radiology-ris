## 二、关键技术产出

### 2.1 Provider 整合(核心)

`src/components/Provider.tsx` 把 v3.0.0 所有能力整合到一个组合器:

```typescript
<Provider>
  <App />
</Provider>

// 内部结构:
<ErrorBoundary onError={captureError}>
  <I18nextProvider i18n={i18n}>
    <ConfigProvider locale={antLocale} theme={...}>
      <AntdApp notification={...} message={...}>
        <SkipLink />
        <LiveRegion />
        {children}
      </AntdApp>
    </ConfigProvider>
  </I18nextProvider>
</ErrorBoundary>
```

**关键能力**:
- 主题(浅色 / 暗色)自动切换
- 错误兜底(ErrorBoundary)+ Sentry 自动上报
- Web Vitals 自动监控
- CSP + Security Meta 自动注入
- i18n 中英 locale 与 antd locale 同步

### 2.2 V3 完整重构示范页(ReportListV3Page)

这个页面是 v3.0.0 技术重构的**最佳实践样本**,展示如何整合:

## 三、文件升级说明

### 3.1 `src/utils/currency.ts`(升级)

**从 2 个函数 → 8 个函数**:

| 函数 | 作用 | 精度 |
|------|------|------|
| `formatCurrency` | 格式化 ¥xxx,xxx.xx | Decimal |
| `parseCurrency` | 解析货币字符串 | - |
| `addCurrency` | 加法(避免浮点) | Decimal |
| `subtractCurrency` | 减法 | Decimal |
| `multiplyCurrency` | 乘法 | Decimal |
| `divideCurrency` | 除法(支持 0 默认值) | Decimal |
| `roundCurrency` | 四舍五入 | Decimal |
| `applyDiscount` | 折扣(百分比 / 小数) | Decimal |
| `calculateVAT` | 增值税(13% / 9% / 6%) | Decimal |

### 3.2 `src/utils/date.ts`(升级)

**从 4 个函数 → 14 个函数**:

| 函数 | 作用 |
|------|------|
| `formatDate` | 格式化日期 |
| `formatDateTime` | 格式化日期时间 |
| `formatDateTimeFull` | 含秒 |
| `formatRelativeTime` | 相对时间("3 分钟前") |
| `addDays` / `addMonths` / `addYears` | 加减 |
| `diffMinutes` / `diffDays` / `diffYears` | 相差 |
| `dayStart` / `dayEnd` | 当天开始/结束 |
| `parseISODate` | 解析 ISO |
| `isToday` / `isPast` / `isFuture` | 判断 |

底层用 `date-fns` + `date-fns/locale`(zhCN / enUS),替代手写实现。
