```typescript
const [state, send] = useMachine(reportMachine, { input: { reportId, patientId, radiologistId } });
const currentState = state.value as ReportStateName;

// 步骤条根据 XState 状态动态计算
const getStep = (s) => {
  if (['pendingAssignment', 'assigned', 'writing'].includes(s)) return 0;
  if (['submitted', 'reviewing', 'reviewed'].includes(s)) return 1;
  if (['signing', 'signed'].includes(s)) return 2;
  if (s === 'published') return 3;
  return -1;
};

<Steps current={getStep(currentState)} status={...} />
```

## 三、@ts-nocheck 策略调整

**新策略**:**不逐个清理(陷入类型细节)**,**用 V3 新页面替代,让 V3 不带 @ts-nocheck**。

实际效果:
- W8 之前:35 个带 `@ts-nocheck` 的页面
- W8 之后:**新写 3 个 V3 页面(均无 @ts-nocheck)**,原 35 个页面仍然带
- 但路由切换到 V3 后,用户实际看到的是 V3 页面(零 @ts-nocheck)
- 原 v0.x 页面已退居"未路由"状态

**最终目标**:把所有 89 页面都 V3 化后,@ts-nocheck 文件自然降为 0。
