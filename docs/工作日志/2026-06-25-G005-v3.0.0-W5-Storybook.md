## 二、关键事件:W4 推送问题

**问题**:W4 阶段虽然每次 `git push` 都返回 "Everything up-to-date",但实际远端 `release/v3.0.0` 分支没有更新。

**根因**:
- 本地 `release/v3.0.0` 分支指针还停在 `4ecea8e`
- 之后的 commits 都在 `main` 分支
- 但 main 分支推送后,gitcode 的 release/v3.0.0 引用没自动同步

**修复**:
```bash
git branch -f release/v3.0.0 c4fc274
git push origin release/v3.0.0 --force-with-lease
# 4ecea8e..c4fc274  release/v3.0.0 -> release/v3.0.0
```

**经验**:
- 推送前 `git log -1 HEAD` 验证分支指向
- 两个分支都 push(不只是默认分支)
- 如果只有 main 在动,应 `git checkout release/v3.0.0 && git merge main` 或重置指针
