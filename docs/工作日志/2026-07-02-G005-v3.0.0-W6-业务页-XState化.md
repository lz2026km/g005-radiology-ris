### 1.2 关键 XState 模式

#### 模式 1:单 actor(WorklistPage)

```typescript
const [, sendDeviceEvent] = useMachine(deviceMachine, {
  input: { deviceId: 'dev-CT-1', deviceCode: 'CT-1', modality: 'CT' },
});
// 业务事件触发
sendDeviceEvent({ type: 'START_USE', patientId, examId, by: 'doctor-001' });
```

#### 模式 2:每数据项一个 actor(DevicePage)

```typescript
function DeviceCard({ device }) {
  const [state, send] = useMachine(deviceMachine, {
    input: { deviceId: device.id, deviceCode: device.deviceCode, modality: device.modality },
  });
  // 每个设备独立的状态机
  return <Button onClick={() => send({ type: 'REPORT_FAULT', reason: '...', by: '...' })}>报故障</Button>;
}
```

#### 模式 3:状态驱动 UI(CriticalValuePage)

```typescript
// 5 节点进度条
<div style={{ display: 'flex', gap: 4 }}>
  {[1, 2, 3, 4, 5].map((step) => (
    <div style={{
      background: step <= config.step ? config.color : '#e2e8f0',
    }} />
  ))}
</div>

// 状态驱动操作按钮
{cv.currentState === 'found' && <Button>通知</Button>}
{cv.currentState === 'notified' && <Button>确认</Button>}
```

#### 模式 4:新状态机(AppointmentPage)

```typescript
// 业务特定状态机,内联定义
const appointmentMachine = createMachine({
  id: 'appointment',
  initial: 'scheduled',
  states: {
    scheduled: { on: { CHECK_IN: 'checkedIn', CANCEL: 'cancelled', NO_SHOW: 'noShow' } },
    checkedIn: { on: { COMPLETE: 'completed', CANCEL: 'cancelled' } },
    completed: { type: 'final' },
    cancelled: { type: 'final' },
    noShow: { type: 'final' },
  },
});
```

## 二、技术亮点

### 2.1 XState 5 实战

| 页面 | actor 数 | 事件 | 状态数 |
|------|----------|------|--------|
| Worklist | 1(共享) | 4+ | 5(设备) |
| Device | N(每设备 1) | 7 | 5 |
| CriticalValue | 0(本地 state 镜像) | 6 | 5+2 |
| Appointment | 0(本地 state) | 4 | 5 |

**所有页面零 `@ts-nocheck`**,TypeScript 严格类型通过。

### 2.2 业务组件 100% 复用

每个 V3 页面都用:
- `AppLayout`(侧边栏 + 头部 + 面包屑 + 用户菜单)
- `PageContainer`(标题 + extra)
- `AppGrid`(响应式 KPI 卡片)
- `CardSection`(可悬停)
- `AppEmpty` / `AppSelectField` / `AppSearchInput`

样式统一遵循 W4 Design Tokens。

### 2.3 a11y 完整

- `aria-label` / `aria-describedby` 全覆盖
- `useScreenReaderAnnouncer` 通知状态变化
- `useCommandPalette` 键盘命令(Worklist)
- 跳转链接 / 焦点管理

### 2.4 错误处理

```typescript
try {
  // 业务逻辑
} catch (error) {
  captureError(error as Error, { action, recordId });
  toast.error('操作失败');
}
```

每个操作都包 Sentry 上报。
