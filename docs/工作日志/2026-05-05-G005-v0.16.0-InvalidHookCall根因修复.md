## 一、问题描述

### 现象
G005系统所有页面白屏，浏览器console报错：
```
Warning: Invalid hook call. Hooks can only be called inside of the body of a function component.
```

### 初步诊断
- tsc编译0错误通过
- vite build构建成功
- preview/dev模式HTTP 200返回
- 但页面空白，无实际渲染

---

## 二、根因定位过程

### 1. AuthorityPage.tsx 问题
```tsx
// ❌ 错误代码（第35行）
const [users, setUsers] = useState<User[]>([...60个用户数据...])

// ✅ 修复后
const usersData: User[] = [...]  // 第35行：顶层常量
// ...
export default function AuthorityPage() {
  const [users, setUsers] = useState<User[]>(usersData)  // 第143行：组件内初始化
```

**问题**：第35行在模块顶层（非组件函数内）调用了useState，违反React规则。

### 2. InsuranceAuditPage.tsx 问题
```tsx
// ❌ 错误代码（第74行）
const [pendingAudits, setPendingAudits] = useState<PendingAudit[]>([...50条数据...])

// ✅ 修复后
const pendingAuditData: PendingAudit[] = [...]  // 第74行：顶层常量
// ...
export default function InsuranceAuditPage() {
  const [pendingAudits, setPendingAudits] = useState(pendingAuditData)  // 第840行：组件内初始化
```

**问题**：同样在模块顶层调用useState。

### 3. 搜索确认范围
```bash
grep -n "^const \[.*\] = useState" src/pages/*.tsx
```
**结果**：仅此两个页面有此问题，其他页面正常。

## 三、修复方案

### AuthorityPage.tsx 修复
1. 第35行：`const [users, setUsers] = useState<User[]>([` → `const usersData: User[] = [`
2. 第96行：`])` → `]`（数组闭合括号修正）
3. 第143行（组件内新增）：`const [users, setUsers] = useState<User[]>(usersData)`

### InsuranceAuditPage.tsx 修复
1. 第74行：`const [pendingAudits, setPendingAudits] = useState<PendingAudit[]>([` → `const pendingAuditData: PendingAudit[] = [`
2. 第125行：`])` → `]`（数组闭合括号修正）
3. 第840行（组件内新增）：`const [pendingAudits, setPendingAudits] = useState(pendingAuditData)`

## 六、经验总结

### 教训
1. **useState禁止在模块顶层调用**：必须在组件函数内部调用
2. **大型数据应作为顶层常量**：数据数组定义为顶层常量，组件内用useState(data)初始化
3. **修复后必须重新构建**：修改hooks后需重新npm run build
