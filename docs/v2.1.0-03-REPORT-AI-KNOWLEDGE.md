### 12.2 14/15 态状态机详解

> 详见分册 02 § 5.2。本节聚焦**业务规则**。

| 分组 | 状态 | 业务含义 | 操作者 |
|------|------|----------|--------|
| **draft** | 待分配 | 检查已完成,系统未分配医生 | 系统 |
| | 已分配 | 已分给某医生,医生尚未打开 | 系统 / 主任 |
| | 书写中 | 医生已打开,正在编辑 | 报告医生 |
| **review** | 已提交 | 医生提交初审 | 报告医生 |
| | 初审中 | 初审医生正在审 | 初审医生 |
| | 初审通过 | 初审医生通过 | 初审医生 |
| | 终审中 | 终审医生正在审 | 终审医生 |
| | 已审核 | 终审通过,待签发 | 终审医生 |
| **sign** | 签发中 | CA 签名 / 盖章中 | 报告医生 |
| | 已签发 | 已签名,未发布 | 报告医生 |
| **published** | 已发布 | 已发布到临床/患者端 | 系统 |
| **special** | 修订中 | 修订流程进行中 | 报告医生 |
| | 已修订 | 修订完成,新版本 | 报告医生 |
| | 已撤回 | 报告被撤回(发布前) | 报告医生 / 主任 |
| | 已驳回 | 审核不通过,打回修改 | 初审 / 终审 |
| | 已归档 | 长期归档(超过 30 天) | 系统 |

**关键业务规则**:
- 待分配 / 已分配可转 已撤回
- 书写中 / 已提交 可转 已驳回 → 回到 书写中
- 已签发 才能 已发布
- 已发布 才能 修订中(新版本)
- 已撤回 / 已驳回 不计入 KPI

### 12.9 CA 数字签名(R6 + R8)⭐

**`services/caService.ts` 能力**:
- 自建 CA(RSA-SHA256 2048-bit)
- 证书签发 / 验证
- 证书链(支持多级)
- 报告签名(`SignedReportPayload`)
- Web Crypto API 浏览器原生实现

**证书结构**:
```typescript
interface Certificate {
  version: 1;
  serialNumber: string;
  subject: { commonName, organization, organizationalUnit, country, emailAddress, userId, role, licenseNumber };
  issuer: { commonName, organization, userId };
  publicKeyJwk: JsonWebKey;
  notBefore: string;
  notAfter: string;
  signatureAlgorithm: 'RSA-SHA256';
  signature: string;
  keyUsage: ['digitalSignature' | 'nonRepudiation' | 'keyEncipherment' | 'dataEncipherment' | 'keyCertSign'];
  extendedKeyUsage?: ['clientAuth' | 'emailProtection' | 'codeSigning'];
  fingerprint: { sha256: string; sha1: string };
}
```

**签名流程**:
1. 报告内容 SHA-256 哈希
2. 用医生私钥签名哈希
3. 签名 + 证书 + 证书链 → 后端
4. 后端验证 → 入库 → 不可篡改

**`pages/CASignaturePage.tsx`**:签名工作台

### 12.10 审计链(Merkle Tree)(R6)⭐

**`services/auditChain.ts`**:
- 不可篡改的操作日志
- Merkle Tree 链式结构
- 每条记录含前序哈希,篡改可被检测

**记录类型**:
```typescript
type AuditAction =
  | 'created' | 'updated' | 'signed' | 'finalized' | 'amended' | 'cancelled'
  | 'reviewed' | 'printed' | 'exported' | 'shared' | 'locked' | 'unlocked'
  | 'image-viewed' | 'annotation-added' | 'critical-notified' | 'collaboration-joined'
  | 'login' | 'logout' | 'permission-changed';

interface AuditEntry {
  seq: number;
  timestamp: string;
  reportId: string;
  actor: string;
  action: AuditAction;
  detail?: string;
  prevHash: string;     // 前一个 hash
  hash: string;          // 当前 hash
  signature?: string;    // base64
  certSerial?: string;
}
```

**Merkle 证明**:
```typescript
interface MerkleProof {
  leafIndex: number;
  leafHash: string;
  siblings: Array<{ hash: string; position: 'left' | 'right' }>;
  rootHash: string;
}
```

**`pages/BlockchainProofPage.tsx`**:存证查看 / 验证
