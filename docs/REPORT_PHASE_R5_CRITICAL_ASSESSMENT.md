## 3. 核心能力

### 3.1 危急值规则配置

**18 条规则 / 7 大类别**：
- 神经（4）：急性脑梗死 / 颅内出血 / 脑疝 / 颅内动脉瘤
- 心血管（4）：急性冠脉综合征 / 主动脉夹层 / 肺栓塞 / 心包填塞
- 胸部（2）：气胸 / 大量胸腔积液
- 腹部（4）：消化道穿孔 / 肝脾破裂 / 肠梗阻 / 异位妊娠破裂
- 创伤（2）：骨折伴移位 / 脊髓压迫
- 血管（1）：颅内动脉瘤（与神经重叠）
- 造影剂（2）：严重过敏 / 外渗

**规则详情**：
- 触发关键字（多选标签）
- 触发所见模式（自动匹配）
- 4 通报渠道（电话/短信/微信/站内，可同时触发）
- 响应时限（5/10/30/60 分钟）
- 临床意义
- 指南参考

### 3.2 危急值统计大屏

**5 大 KPI**：本月危急值 23 / 待通报 2 / 已处理 19 / 10分钟通报率 91.3% / 平均响应 7.2m

**病种分桶**：神经 6 / 心血管 7 / 胸部 4 / 腹部 4 / 创伤 1 / 血管 1（彩色条形图）

**设备分桶**：CT 18 / MR 3 / DR 1 / US 1

**Top 5 排行**：急性脑梗死 5 / 急性冠脉 4 / 气胸 3 / 穿孔 3 / 肝脾破裂 2

**医生排行**：张明远 6 例 / 赵雪琴 5 例 / 李慧敏 4 例（含响应时间）

**最近事件流**：8 条详细记录（含状态徽标 + 及时/超时标签 + 响应分钟数）

### 3.3 8 大分类评估

**统一组件 + URL 参数切换**：
- `/special-assessment?system=birads` → BI-RADS
- `/special-assessment?system=lungrads` → Lung-RADS
- ... 共 8 个

**8 大系统 + 等级**：
| 系统 | 等级数 | 适用 |
|---|---|---|
| BI-RADS | 9 (0-6 + 4A/4B/4C) | 乳腺钼靶 |
| Lung-RADS | 6 (1-4B/4X) | 胸部 CT |
| PI-RADS | 5 (1-5) | 前列腺 MR |
| CAD-RADS | 7 (0-5) | 心脏 CTA |
| TI-RADS | 7 (1-5) | 甲状腺 US |
| RECIST 1.1 | 4 (CR/PR/SD/PD) | 实体瘤 CT |
| 骨龄 | 3 (TW3/中华05) | DR |
| 心脏 CTA | 4 (优/良/可/受限) | CT |

**评估功能**：
- 评估项目表单（select/number/boolean）
- 等级选择（彩色按钮，描述 + 行动建议）
- 历次评估记录（可展开）
- 保存评估

### 3.4 CriticalValuePage 升级入口

顶部红渐变横幅（v1.0.5 升级标识）：
- 规则配置 → 跳转至 CriticalValueRulePage
- 统计大屏 → 跳转至 CriticalValueStatsPage

## 5. 用户视角演示路径

### 路径 1：规则配置
1. 打开 `/critical-value-rule`
2. 顶部 KPI：本月 23 / 待通报 2 / 10分钟率 91.3%
3. 左侧 18 条规则列表（按类别过滤）
4. 选中"cv-001 急性脑梗死" → 右侧详情
5. 关键字：脑梗死/缺血/梗死/stoke
6. 通报渠道：电话 + 站内 + 短信（10分钟响应）

### 路径 2：统计大屏
1. 打开 `/critical-value-stats`
2. 顶部 5 大 KPI（带趋势箭头）
3. 左：按病种分桶（7 类别条形图）
4. 中：按设备分桶（CT 主导 78%）
5. 右下：医生排行（张明远居首）
6. 底部：最近 8 条事件（含及时/超时）

### 路径 3：BI-RADS 评估
1. 打开 `/special-assessment?system=birads`
2. 顶部粉红渐变头部
3. 左：评估项目（腺体密度/肿块/钙化等 7 项）
4. 右：9 个等级（0 类 - 5 类）彩色按钮
5. 选"4B 类" → 详情 + 行动建议
6. 展开历史记录

### 路径 4：CAD-RADS 评估
1. 切换 URL `?system=cadrads`
2. 红色渐变头部
3. 4 支冠脉狭窄评估（LM/LAD/LCX/RCA）
4. 7 个等级（0-5）
