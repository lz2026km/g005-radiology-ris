## 3. 核心能力

### 3.1 关键字全量扫描

**6 大类规则统计卡片**（顶部）：解剖方位 4 / 逻辑矛盾 5 / 否定词 6 / 标点 6 / 标准格式 5 / 病灶关键词 30+

**扫描流程**：
- 左侧 50 报告列表
- 选中后点击"开始扫描"
- 真实进度条 0-100% 动画
- 调用 `checkKeywords()` 引擎
- 右侧展示：错误/警告/提示 计数 + 总评分 + 80 分通过线
- 严重度 + 类别 双过滤
- 问题列表 + 详情面板（严重度/类别/规则ID/位置/建议）

**集成 R1 引擎**：复用 keywordChecker.ts，零代码重复

### 3.2 多维评分规则

**5 大维度 + 权重配置**：
- 完整性 30% / 规范性 20% / 准确性 25% / 及时性 15% / 术语规范 10%
- 权重滑块 0-100%（合计需 = 100%）
- 评估标准 5 条/维度
- 评分规则 5 条/维度（100/85/70/50/30 分对应条件）

**4 级等级映射**：甲 (90-100) / 乙 (75-89) / 丙 (60-74) / 丁 (0-59)

**KPI 概览**：累计评分 1248 / 平均分 87.5 / 甲级率 50% / AI 采纳率 78.5% / 需重训 23

### 3.3 缺陷分类字典

**6 大分类 / 17 缺陷**：
- 描述问题（4）：过于简单/不清/重复/与图不符
- 术语问题（3）：不规范/缩写/错别字
- 格式问题（3）：CT值/尺寸/标点
- 逻辑问题（3）：阴/阳/左右/否定词
- 危急值（2）：未标识/未通报
- 完整性（3）：缺所见/缺意见/缺建议

**Top 5 排行**（橙色横幅）：CT值缺单位 198 / 描述简单 156 / 尺寸不规范 156 / 术语不规范 134 / 缩写不规范 78

**3 级严重度**：严重（红）/ 重要（黄）/ 轻微（蓝）

**详情面板**：编码 / 触发次数 / 描述 / 典型示例 / 解决方案

### 3.4 AI 一键自动初稿

**6 大场景模板**：
- 胸部 CT 平扫筛查
- 肺结节筛查
- 肝脏占位评估
- 脑梗死急诊
- 腰椎间盘突出
- 乳腺钼靶筛查

**6 阶段生成动画**：分析病史 → 提取症状 → 匹配相似病例 → 调用 AI v2.3 → 应用术语 → 生成完成

**3 大输出区**：
- 临床病史输入（textarea）
- AI 场景模板列表（带置信度）
- 生成结果（所见/诊断/意见 可编辑）

**置信度 + 3 个参考来源**：AI 模型 v2.3 / 卫健委指南 / 12 篇文献

**应用流程**：选中报告 → 输入病史或模板 → 一键生成 → 编辑调整 → 应用到 ReportWriteV2Page

## 5. 用户视角演示路径

### 路径 1：扫描关键字
1. 打开 `/keyword-check`
2. 左选"rpt-013 黄海涛"
3. 点击"开始扫描" → 进度 0-100%
4. 右侧显示：评分 92、错误 0、警告 2、提示 3
5. 过滤"警告" → 显示 2 个问题
6. 点击"FMT-001" → 右侧详情显示"CT 值缺单位"建议

### 路径 2：配置评分规则
1. 打开 `/report-score-rule`
2. 左选"完整性" → 滑块调到 35%
3. 评估标准 5 条 + 评分规则 5 条
4. 切换到"术语规范" → 当前权重 10%
5. 右侧等级映射：甲 90-100 / 乙 75-89 / 丙 60-74 / 丁 0-59
6. 点击"保存配置"

### 路径 3：浏览缺陷字典
1. 打开 `/report-defect-library`
2. 顶部 6 分类统计卡片
3. Top 5 排行横幅
4. 左侧搜索"CT值" → 显示 FMT-001
5. 右侧详情：CT 值缺单位 / 触发 198 次 / 示例 / 解决方案

### 路径 4：AI 一键初稿
1. 打开 `/ai-report-draft`
2. 左选"rpt-013 黄海涛" → 自动填充临床病史
3. 选场景模板"肺结节筛查"（88% 置信度）
4. 点击"一键生成" → 6 阶段动画
5. 右侧生成：所见/诊断/意见（可编辑）
6. 点击"应用到报告书写" → 跳转到 ReportWriteV2Page
