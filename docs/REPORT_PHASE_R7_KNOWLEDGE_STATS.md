## 1. 概述

Phase R7 是报告子系统 (R0-R7) 八阶段重构的**收官阶段**。本阶段聚焦于"知识资产沉淀 + 业务度量分析"，为系统提供
- 长期积累的放射学术语库、短语库
- 多维度 KPI 监控大盘
- 医生工作量与诊断符合率分析
- 报告及时率实时监控
- 高级全文检索能力

R7 完成后，G005 系统在报告子系统的对标能力上达到 **47 项国内厂商覆盖**（Winning/东软/联影/GE/飞利浦/卡易/锐珂/久远/一脉阳光/英飞达），为放射科日常运营、科研和管理提供完整闭环。

## 4. 关键设计模式

### 4.1 术语同义词图谱
- **SVG 极坐标布局**: 中心节点 + 周围 8-12 个同义词/相关词
- **颜色编码**: 中心紫色 #7c3aed / 同义词紫色 / 相关词蓝色
- **连线样式**: 实线（同义词）/ 虚线（相关词）
- **点击聚焦**: 切换到任意词条重新布局
- **分类筛选**: 7 大分类 Tab
- **使用次数热度**: 节点大小 / 字号

### 4.2 短语库占位符替换
- **格式**: `{{placeholder}}` 双花括号
- **示例**: `{{location}} 见一 {{size}} 的 {{density}} 病灶`
- **常见占位符**: location / size / density / boundary / apEnhance / vpEnhance
- **一键复制**: 剪贴板写入替换后的文本

### 4.3 KPI 大盘指标分层
- **4 大核心 KPI**: 报告数 / 平均签发 / 甲级率 / AI 采纳
- **5 大次要 KPI**: 已签发 / 待签发 / 危急值及时率 / 质量分 / 区块链
- **可视化组件**: 横向进度条 / 24h 柱状图 / 7d 柱状图 / 设备利用率柱状图

### 4.4 医生工作量 6 维度评分
- **数量**: totalReports
- **质量**: qualityScore
- **时效**: avgSignTime
- **危急值**: criticalValueHandled
- **会诊**: consultingHours
- **设备**: byModality 分布

### 4.5 诊断符合率金标准
- **病理证实的黄金标准**: 通过术后病理 / 穿刺活检验证
- **临床证实**: 通过临床治疗反应 / 实验室检查验证
- **影像随访**: 通过后续影像复查验证
- **四性指标**: 灵敏度 / 特异度 / PPV / NPV

### 4.6 报告及时率 TAT
- **优先级 TAT 目标**:
  - 急诊: 5 分钟（红）
  - 加急: 30 分钟（黄）
  - 普通: 24 小时（蓝）
- **实时监控**: 自动刷新 + 超时自动升级
- **催办 / 升级**: 一键推送通知 + 升级到上级医生

### 4.7 高级检索
- **全文搜索**: 患者 / 所见 / 印象 / 诊断 / 标签
- **智能联想**: 实时显示相关术语 + 短语建议
- **7 维筛选**: 设备 / 部位 / 医生 / 状态 / 起止日期 / 评分 / 标签
- **结果统计**: 结果数 / 平均分 / 危急值数 / 及时率
- **导出**: CSV
