## § 15. 扩展子系统

> ⭐ 本章涵盖 v0.15.0 § 8 完全未提及 / 简表一笔带过的 27 个独立子系统。

### 15.1 临床数据中心(CDR) ⭐

`utils/clinicalDataCenter.ts`(Zod 校验):

**数据类型**:
| 类型 | 描述 |
|------|------|
| `lab` | 检验结果(血常规 / 生化 / 免疫 / 凝血 / 尿常规 / 粪便常规 / 感染标志物 / 肿瘤标志物 / 内分泌) |
| `diagnosis` | 诊断记录(活动性 / 非活动性 / 待确诊 / 已排除) |
| `medication` | 用药记录(口服 / 静脉 / 肌注 / 皮下 / 外用 / 吸入) |
| `allergy` | 过敏史(轻度 / 中度 / 重度 / 危及生命) |
| `procedure` | 操作记录 |
| `vital` | 生命体征 |

**价值**:放射科检查申请时,自动拉取患者近期检验/诊断/用药/过敏,辅助报告决策。

**关联页面**:`pages/ClinicalDataPage.tsx`

### 15.2 DRG/DIP 分组器 ⭐

`utils/drgDipGrouper.ts`:

- 支持中国 DRG(Diagnosis Related Groups)分组
- 支持 DIP(Diagnosis-Intervention Packet)分组
- 主诊断推荐
- 费用计算(基础费用 × 权重)
- MDC(Major Diagnostic Category)分类
- 异常病例标识

**典型流程**:
```
输入: 主诊断 + 其他诊断 + 手术/操作 + 年龄 + 性别
  ↓
DRG 分组器
  ↓
输出: { code, name, weight, baseFee, mdcCode, mdcName, isException }
```

**关联页面**:`pages/CostAnalysisPage.tsx`

### 15.3 HIE 医疗信息交换适配器 ⭐

**支持协议**:

const ObservationSchema = z.object({

**关联页面**:`RegionalImagingPage.tsx` / `RegionalReportPage.tsx`

## 附录 D FAQ

### D.1 部署与运行

**Q:启动 dev server 失败 `pnpm dev` 报错?**
A:确保 Node.js ≥ 20,执行 `pnpm install` 完整安装依赖。如仍报 `InvalidHookCall`,见 `docs/工作日志/2026-05-05-G005-v0.16.0-InvalidHookCall根因修复.md`。

**Q:如何跑测试?**
A:`pnpm test:run`(CI 模式)/ `pnpm test`(watch)。

**Q:Storybook 怎么用?**
A:`pnpm storybook` → http://localhost:6006

### D.2 数据与状态

**Q:数据是真实数据库还是 Mock?**
A:当前是 27+ Mock 文件 + localStorage + IndexedDB(Dexie)。生产环境需要后端,见分册 01 § 3.2。

**Q:多人协同能用吗?**
A:2-5 人可以用 y-webrtc P2P。超过 5 人或需多端同步,必须上后端 WebSocket。

**Q:数据会丢失吗?**
A:localStorage 5-10MB 限制,Dexie 支持大数据但仍是浏览器本地。建议定期导出备份。

### D.3 影像

**Q:DICOM 影像能加载真实文件吗?**
A:可以,`pages/DicomViewerPage.tsx` 支持本地上传;远程 PACS 需配置 `services/dicomWeb.ts` 的 baseUrl。

**Q:支持哪些 DICOM 操作?**
A:窗宽窗位 / 缩放 / 旋转 / 测量 / 标注 / MPR / MIP / VR / 伪彩 / 对比 / 打印布局。完整列表见分册 02 § 7.9。

### D.4 报告

**Q:14 态状态机在哪定义?**
A:`src/data/reportSubsystemMock.ts` 的 `REPORT_STATUS_GROUPS`。

**Q:CA 签名能用吗?**
A:前端 `services/caService.ts` 用 Web Crypto API 实现了完整的证书签发/验证/签名,可演示。生产需对接国家 CA 服务。

**Q:协同报告如何接入?**
A:见 `services/collaboration.ts` + `hooks/useCollaborativeReport.ts`。默认 P2P 房间,无需服务端。

### D.5 AI

**Q:DeepSeek 怎么配置?**
A:环境变量 `VITE_DEEPSEEK_API_KEY` / `VITE_DEEPSEEK_BASE_URL`,通过 `createDeepSeekFromEnv()` 初始化。

**Q:RADS 分级准吗?**
A:数据规则 100% 符合官方标准;但 RADS 应用需结合影像所见,系统仅提供辅助决策。

**Q:AI 推理需要 GPU 吗?**
A:当前 LLM 调用 DeepSeek 外部 API。影像 AI(肺结节 / 乳腺 / 骨折)需后端 GPU 推理服务(v2.6.0 计划)。

### D.6 文档

**Q:`SYSTEM_DOCUMENTATION.md` 还能看吗?**
A:已标记 legacy,内容已过期。新文档以 v2.1.0 系列为准,见 `docs/v2.1.0-INDEX.md`。

**Q:如何给文档做贡献?**
A:从 v2.1.0 大纲(`v2.1.0-DOCUMENTATION_OUTLINE.md`)找到未完成小节,补充正文后提 PR。
