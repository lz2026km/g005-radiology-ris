## 1. 概述与市场定位 (Overview & Market Position)

### 1.1 Siemens syngo 在中国市场的位置

| 产品线 | 定位 | 中国市场份额 |
|---|---|---|
| **syngo.plaza** | 放射科 PACS (服务器) | ~15% (三甲医院主力) |
| **syngo.via** | 高级后处理工作站 (VB10/VB30/VB50/VB60/VB70) | 高端 CT/MR 后处理标配 |
| **syngo Workflow Orchestrator** | 扫描协议管理 / 任务调度 | SOMATOM 配套 |
| **AI-Rad Companion** | Siemens 官方 AI 平台 (胸部 CT 2020+, 头颈 MR 2022+) | 高增长 |
| **teamplay** | 设备/流程性能监控 | SOMATOM/MAGNETOM 配套 |
| **syngo Carbon** | 非 DICOM 影像归档 (照片/PDF) | 边缘产品 |
| **Cinematic VRT / InSpace4D** | 高级 VR (心脏/血管) | 心脏专科 |

**对 G005 RIS 的意义**:

Siemens 在中国大型医院的装机特点: **CT/MR 设备是 SOMATOM/MAGNETOM, 后处理基本是 syngo.via, PACS 70% 是 syngo.plaza, 20% 是其他厂商**。客户场景:

1. **检查 (Order)** → SOMATOM/MAGNETOM 扫描协议推送
2. **报告 (Report)** → syngo.via Findings/Images 双向通道
3. **胸部 CT AI** → AI-Rad Companion 触发
4. **心脏 CTA** → CoronaryAngiography 应用
5. **剂量管理** → syngo.via RDSR + teamplay 集成
6. **性能监控** → teamplay Dashboard 数据对接

## 3. 模块详细设计 (Module Breakdown)

### 模块 1: VIS 3D Volume Rendering (52 升级点)

#### 3.1.1 功能说明

模拟 syngo.via InSpace4D / Cinematic VRT 风格的体绘制。**MVP 实现**:

- **VR (Volume Rendering)**: Three.js ray casting, 8 个预设色彩表 (CT Bone / CT Angio / CT Soft / MR T1 / MR T2 / PET)
- **MIP (Maximum Intensity Projection)**: 简化版 slab MIP
- **MPR (Multi-Planar Reconstruction)**: 3 平面 (Axial / Sagittal / Coronal) + 任意斜面
- **CPR (Curved Planar Reformation)**: 沿血管中心线展开 (Mock, 中心线手工标注)
- **裁剪平面**: 6 个方向 cube clip
- **渲染预设**: 15 个 (syngo.via 风格命名)

**MVP 真实渲染范围**:

- 数据: 不加载真实 DICOM, 用合成 256×256×200 体数据 (Mock generated)
- 性能: 桌面端 WebGL2 60 FPS 目标, 移动端降级到 30 FPS

```ts
interface SiemensVolumeRenderRequest {
  studyInstanceUID: string;
  volumeDataUrl?: string;       // 真实场景下是 DICOM WADO-RS URL
  volumeFormat: 'dicom' | 'mock-cube' | 'nifti';
  preset: VolumePreset;
  renderMode: 'VR' | 'MIP' | 'MPR' | 'CPR' | 'ThinSlab' | 'Cinematic';
  clipping?: {
    enabled: boolean;
    planes: Array<{ axis: 'x'|'y'|'z'; position: number; inverted: boolean }>;
  };
  windowLevel?: { ww: number; wl: number };
  opacity?: number;             // 0..1
  quality: 'draft' | 'standard' | 'high';
}

type VolumePreset =
  | 'ct-bone' | 'ct-angio' | 'ct-soft' | 'ct-lung' | 'ct-liver'
  | 'mr-t1' | 'mr-t2' | 'mr-flair' | 'mr-dwi'
  | 'pet-hotmetal' | 'pet-rainbow' | 'pet-grayscale';

interface SiemensVolumeRenderResponse {
  studyInstanceUID: string;
  preset: VolumePreset;
  renderMode: string;
  fps: number;
  frameTime: number;
  fpsHistory: number[];         // 最近 60 帧
  thumbnailPngBase64?: string;  // Mock 截图
  screenshotUrl?: string;
  metadata: {
    volumeDimensions: { x: number; y: number; z: number };
    spacing: { x: number; y: number; z: number };
    modality: string;
    bodyPart: string;
  };
}
```

### 模块 3: CAD — Computer Aided Detection (44 升级点)

#### 3.3.1 功能说明

模拟 syngo.CT Lung CAD + CT Colonography CAD:

**Lung CAD**:

- 实性结节 (≥4mm)
- 部分实性结节 (≥5mm)
- 磨玻璃结节 (≥5mm)
- 钙化结节 (良性, 不报警)
- Lung-RADS 自动评级

**Colon CAD**:

- 6-9mm 息肉
- ≥10mm 息肉
- 肠腔内隆起
- C-RADS 评估

**MVP 范围**: 仅 Lung CAD 完整实现, Colon CAD 用统一接口占位。

## 6. 与现有 RIS 的集成点

### 6.1 检查 (Exam) 模块

- **触发 AI-Rad**: 当 `Exam.modality === 'CT' && Exam.bodyPart === '胸部' && Exam.contrastUsed === true`, 自动调用 AI-Rad
- **触发 CAD**: 当 `Exam.bodyPart === '胸部'`, 异步调用 Lung CAD
- **触发 Cardiac**: 当 `Exam.bodyPart === '心脏'`, 异步调用 Cardiac CTA/MR

### 6.2 报告 (Report) 模块

- **模板替换**: 选 syngo 模板时, 字段自动从 CAD/AI-Rad 填充
- **VR 截图**: 报告编辑时可插入 VR 视图
- **3 段牛眼图嵌入**: MR Cardiac 报告自动包含牛眼图

### 6.3 设备 (Device) 模块

- **设备档案**: 新增 `device.siemensModel` 字段 (SOMATOM Force / MAGNETOM Skyra 等)
- **协议绑定**: Device ↔ SiemensScanProtocol 多对多

### 6.4 剂量模块

- **DoseTrackPage**: 合并展示 Siemens RDSR + G005 原生剂量
- **teamplay 数据**: 单独面板, 用于设备层面对比

### 6.5 统计模块

- **StatsReportPage**: 新增"Siemens 设备利用率"报表
- **协议使用频率报表**: 单独 SQL 视图
