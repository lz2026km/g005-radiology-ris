本文档只描述 **v3.0.6.1 实际交付** 的 GE Centricity PACS 前端 MVP,**不包含**:

- ❌ 真实 GE Centricity DICOM Q/R、WADO-RS、STOW-RS 客户端调用
- ❌ 真实 GE Centricity IHE 集成引擎(KIN / PIR / ARI 配置文件)

- ❌ 真实 GE DoseWatch RDSR 监听与 DICOM SR 写入
- ❌ 真实 GE Seno Iris / R2 ImageChecker CAD 嵌入式集成

## §1 GE Centricity PACS 概述与市场地位

### 1.1 厂商背景

GE HealthCare(从 GE 集团 2023 年拆分独立,NYSE: GEHC)在中国大陆装机量约 **800+ 套**(2024 年公司年报披露口径,含三甲与大型二级医院),与西门子、飞利浦、富士、AGFA、佳能共同占据中国放射 PACS 主战场。其面向诊断放射科的核心产品线:

| 产品 | 定位 | 关键能力 |
|---|---|---|
| **Centricity PACS** | 主服务器 + 长归档 | DICOM Q/R, WADO, HL7 ORM/ORU |
| **Centricity Universal Viewer (UV6)** | 零足迹 Web 阅片 | 多模态 MPR/MIP/3D, KIN, PIR |
| **Edison Platform** | AI 编排与算法市场 | TriageCT(ICH/PE/Stroke)、Critical Results |
| **DoseWatch** | 剂量管理 | RDSR 解析, DRLS 对比, 实时告警 |
| **Seno Iris** | 乳腺专用工作站 | Tomo, Contrast Enhanced MG |
| **R2 ImageChecker / SenoCAD** | 乳腺 CAD | 微钙化/肿块/扭曲检测 |
| **AW Workstation / VolumeShare** | 高级可视化 | 心血管/神经/灌注 |
| **Muse ECG** | 心电专用 | 独立产品线, 不在本文范围 |

### 1.2 v3.0.6.1 选型 GE 的理由

G005 RIS v3.0.6 系列按厂商分别发布 7 个 PACS 适配器规范(B1~B7),**GE 排第一** 的原因:

1. **急诊 AI 场景最丰富**:Edison TriageCT 在中国三甲医院急诊卒中/胸痛中心装机率高,2024 年公开白皮书声称 ICH 检测灵敏度 0.96,假阳率 0.04
2. **剂量管理历史最长**:DoseWatch 自 2012 年上市,是中国放射防护条例配套采购的常选项
3. **乳腺工作流标准**:R2 ImageChecker 是中国两癌筛查项目的事实标准,BI-RADS 自动评分渗透率高
4. **教学病例生态**:Centricity Teaching File 兼容 RSNA MIRC, 临床教学数据存量最大

### 模块 2: Smart Worklist — 优先级动态评分(**40 功能点**)

**评分公式**(模拟 GE Centricity Priority Worklist):

```
score = w1 * acuity            // 临床紧急度: P0=100, P1=70, P2=40, P3=10
      + w2 * waitingMin        // 等待分钟数
      + w3 * statFlag          // 急诊标记加成: +30
      + w4 * age               // 高龄加权: >70 岁 +20, >80 岁 +30
      + w5 * contrast          // 含造影剂: +15
      - w6 * readProgress      // 已读进度惩罚: 0..-30
```

**默认权重**:`w1=1.0, w2=0.5, w3=30, w4={age>70:20, age>80:30}, w5=15, w6=0.3`,可在适配器配置页调整。

**40 个功能点拆解**:

| 区间 | 点数 | 内容 |
|---|---|---|
| 评分公式 | 8 | 6 权重独立可调、实时重算、得分明细可展开 |
| 表格渲染 | 10 | 设备/班次/状态过滤、AI 标签徽标、得分热力条、虚拟滚动 |
| 动态优先级 | 7 | 新检查到达自动插入头部、状态变更重排、超时 P0 高亮 |
| 详情弹层 | 6 | 患者/检查/AI/历史/报告状态五合一 |
| 手动调序 | 5 | 主任可拖拽覆盖算法(锁定 30 分钟) |

interface GeRdsrRecord {

  drlsComparison: {
    bodyPart: string;

    drlsCTDIvol: number;
    ratio: number;                  // 实测/DRLS

  };
