## 1. 概述与市场定位 (Overview & Market Position)

**Fujifilm Healthcare** (前身为 Fujifilm Medical Systems, 2021 年从母公司 Fujifilm 拆分独立公司, 主营医疗 IT 与医学影像) 在全球 PACS 市场排名前 5, 在日本本土市场份额第一。在中国市场:

| 维度 | 数据 (估算, 2025) |
|---|---|
| 三甲医院装机量 | ~600 家 |

### 2.3 数据流预研

| 数据流 | 方向 | 协议 | 频率 | 数据量 |
|---|---|---|---|---|
| 检查订单 | G005 → Synapse | HL7 ORM | 实时 | ~500 字段/条 |
| 检查状态 | Synapse → G005 | HL7 ORU | 实时 | ~200 字段/条 |
| 患者信息 | 双向 | HL7 ADT | 实时 | ~150 字段/条 |
| 影像检索 | G005 → Synapse | DICOM Q/R (C-FIND/C-MOVE) | 按需 | 按检查 |
| 影像上传 | 双向 | DICOM STOW-RS / C-STORE | 按需 | 按 GB |
| AI 标注 | Synapse AI → G005 | DICOM SR / JSON | 异步 | ~1 MB/标注 |
| 报告回写 | G005 → Synapse | HL7 ORU + PDF | 实时 | ~500 KB |
| 剂量同步 | Synapse → G005 | DICOM RDSR | 实时 | ~10 KB/次 |

| 技术点 | Fujifilm 实现 | G005 集成方案 (预研) |
|---|---|---|
| DICOM 上限 | Synapse 7x 支持 DICOM 2024b | fo-dicom 5.x 兼容 |
| HL7 版本 | v2.5 / v2.7 (中国版通常 v2.5) | NHapi 5.x |
| 字符编码 | GB18030 / UTF-8 | 需双编码支持 |
| API 认证 | OAuth 2.0 + API Key | Passport.js |

| 性能要求 | 亚秒级阅片延迟 | 复用 Cornerstone 优化 |

## 3. 模块预研 (Module Pre-Research)

> 本节为未来 v3.0.7+ 实施做技术预研, **不交付任何代码**

### 3.1 候选模块 1: Synapse 3D 后处理

**Fujifilm Synapse 3D 功能**:

| 子模块 | 功能 |
|---|---|
| Volume Rendering | 体绘制 (与 syngo.via InSpace4D 对标) |
| Vessel Analysis | 血管分析 (冠脉/外周血管) |
| Lung Analysis | 肺结节 / 肺气肿 / 灌注 |
| Colon Analysis | 结肠 CT 虚拟内镜 |
| Cardiac Analysis | 心脏 CT/MR |
| Neuro Analysis | 头颅 MR 灌注 / 弥散 |
| Orthopedic | 骨科 3D 测量 |

**集成方案 (预研)**:

- 组件结构: 复用 Siemens `Vis3dVolumeRenderer.tsx` 基础 + Fujifilm 特定预设
- API 契约: 复用 Siemens `SiemensVolumeRenderRequest`, 改为 Fujifilm 类型
- 工作量: 约 8 人周 (含 UI 适配 + Mock 数据 + 集成测试)

### 3.2 候选模块 2: Synapse VNA

**VNA 核心功能**:

- **标准化 DICOM 存储**: 接受任意厂商 DICOM
- **生命周期管理**: 在线 / 近线 / 离线 三级存储
- **跨院区共享**: IHE XDS-I.b 注册中心
- **数据迁移**: 老系统数据导入

**集成方案 (预研)**:

- 与 G005 原生 VNA 模块 (R3 已实现) 协同
- 双 VNA 架构: G005 VNA (主) + Synapse VNA (镜像/备份)
- 工作量: 约 16 人周 (含数据迁移工具)

### 3.3 候选模块 3: Synapse AI Platform

**AI 平台功能**:

- 算法注册中心 (类似 Philips AI Manager)
- 算法市场 (Algorithm Marketplace)
- 工作流编排
- 结果聚合 (Multi-Algorithm Fusion)

**集成方案 (预研)**:

- 复用 R3 已有 AI 框架 (registry/router/aggregator)
- Fujifilm 算法以 "third-party" 形式接入
- 工作量: 约 12 人周

### 3.4 候选模块 4: Synapse Mobility

**Mobility 功能**:

- HTML5 零下载阅片
- iOS / Android 原生 App
- 离线阅片缓存

**集成方案 (预研)**:

- 复用 G005 现有 `DicomViewerLite` (R2)
- Fujifilm 特定布局 (暗色 UI)
- 工作量: 约 6 人周

### 3.5 候选模块 5: Synapse Radiology RIS 兼容

**与 Fujifilm Synapse Radiology 双向通信**:

- 订单 → Fujifilm Radiology
- 报告 ← Fujifilm Radiology
- 患者/排班 同步

**集成方案 (预研)**:

- 与 GE/Siemens/Philips 通用 HL7 ORM/ORU 通道
- 工作量: 约 8 人周 (主要是字段映射)
