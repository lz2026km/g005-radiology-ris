## §1 Canon Vitrea 概述

### 1.1 厂商背景

**Canon Medical Systems**(原 Toshiba Medical,2016 年被 Canon 收购)是日本/全球排名前五的医学影像设备与 IT 解决方案提供商。Canon Medical 在 CT、MR、超声、血管造影、分子影像等领域拥有完整产品线。在中国市场,Canon Medical 通过佳能医疗(中国)有限公司开展业务,客户群以三级综合医院、肿瘤医院、心血管专科医院、医科大学附属医院为主。

在中国市场,Canon Medical 的产品装机特点:

- **CT 系列**:Aquilion ONE / PRIME / Lightning 系列(64 排 / 256 排 / 640 层),覆盖中高端 CT 市场;
- **MR 系列**:Vantage Galan 3T、Vantage Orian 1.5T,在心脏 MR、神经 MR 领域装机量较大;
- **高级后处理**:Vitrea Workspace 是 CT/MR 高级可视化的事实标配,与 Siemens syngo.via、Philips IntelliSpace Portal 三分天下;
- **分子影像**:Cartesion Prime PET/CT 在肿瘤核医学装机量增长迅速。

### 1.2 Vitrea 产品矩阵

Canon Vitrea 是 Canon Medical 的"高级可视化与多模态分析"产品族,定位为医院级 / 跨科室级后处理平台:

| 产品 | 定位 | 主要客户 | 与 G005 RIS 关系 |
|------|------|----------|------------------|
| **Vitrea Workspace 7.x** | 高级可视化(MVR/MIP/CPR/3D VR) | 放射科 | 影像后处理调用入口 |
| **Vitrea Cardiac Suite** | 心脏 CT/MR 后处理 | 心内 / 影像 | 钙化评分、17 段牛眼图、Strain |
| **Vitrea Multi-Modality Fusion** | 多模态配准融合(PET/CT、MR/CT、SPECT/CT) | 肿瘤 / 影像 | 配准矩阵 + SUV 统计 + PI-RADS |
| **Vitrea 3D Printing Lab** | 3D 打印(STL 导出 + 实验室对接) | 骨科 / 心外科 / 口腔 | STL 文件 + 打印任务编排 |
| **Vitrea Cloud** | 云端影像存储 / 查看 / 分享 | 全院 / 转诊 | 云端上传 + 阅片链接 + 分享 |

### 1.3 在 G005 RIS 体系中的角色

对 G005 RIS 而言,Vitrea 的角色会随客户形态而变化:

| 形态 | Vitrea 的角色 | G005 RIS 的职责 |
|------|-------------|-----------------|
| Vitrea 作为科室级后处理 | Canon CT/MR 设备的后处理标配 | 登记、报告、计费、工作流 |
| Vitrea 作为多模态融合平台 | PET/CT、MR/CT 融合主导 | 提供检查列表、报告回写 |
| Vitrea Cloud 作为云端分发 | 二级医院 / 转诊 / 患者门户 | 检查主权威,云端镜像分发 |

本文档以**形态一(科室级后处理)** 为主线,覆盖形态二(融合)、形态三(云端)的字段契约。MVP 阶段不承诺任何真实集成,所有"对接"均以 Mock 形式呈现。

### 1.4 MVP 取舍

### 2.4 数据流

1. **检查登记触发**:RIS 登记 Canon 设备完成的检查 → 通过 Study UID 查询既有 DICOM 网关 → 拉取影像元数据 → 在前端组件中渲染;
2. **后处理调用**(MVP):前端组件调用 `b7-canon-adapter.ts` 的 mock 函数 → MSW 拦截 → 返回 fixture 数据;
3. **结果回写**(MVP):渲染完成后,结果对象存储到 `useB7CanonAdapterStore` → 可被报告模块引用;
4. **生产环境**(v3.0.7+):替换 mock 为真实 Canon Gateway Adapter 调用,字段契约保持不变。

### 模块 1: Vitrea Workspace 高级可视化 (50 升级点)

#### 3.1.1 功能说明

**Vitrea Workspace** 是 Canon Medical 的核心高级可视化平台,在三甲医院放射科装机率较高。其核心能力:

- **Multi-Volume VR (MVR)**: 同步显示多套影像的体绘制(CT 增强 + CT 平扫);
- **Curved MPR**: 沿血管中心线展开的曲面重建(CPR);
- **ThinSlab MIP**: 任意厚度的 Slab MIP,适合肺结节、冠脉追踪;
- **Vitrea 预设**: 30+ Vitrea 风格预设(肝脏、血管、骨、肺、心脏等);
- **Vitrea 风格 UI**: 偏白底、Verdana 字体、多窗格布局。

**MVP 范围**:

- 复用 B2 (Siemens) 的 Three.js 基础渲染器;
- 新增 15 个 Vitrea 风格预设(肝脏、血管、骨、肺、心脏、MR 多序列、PET 融合等);
- UI 偏白底 Vitrea 风格,与 Siemens syngo.via 的暗色风格区分;
- 不实现真实 Vitrea 引擎调用。

### 模块 2: Cardiac Suite 心脏后处理 (45 升级点)

#### 3.2.1 功能说明

**Vitrea Cardiac Suite** 是 Canon Medical 在心脏 CT/MR 后处理领域的旗舰产品:

**CT Cardiac(冠脉 CTA)**:

- 冠脉树 3D 重建(LM / LAD / LCX / RCA 各段);
- 钙化评分(Calcium Volume,**Vitrea 特有字段**,与 Agatston Score 区别在于体积 vs 面积加权);
- 心脏功能(LVEF / EDV / ESV / SV / CO / LV Mass);
- 瓣膜评估(主动脉瓣、二尖瓣、三尖瓣、肺动脉瓣);
- 斑块分型(钙化斑块、混合斑块、软斑块);

**MR Cardiac**:

- 17 段 AHA 牛眼图(Bullseye Plot);
- T1 Mapping(Native / Post / ECV);
- T2 Mapping;
- Strain 分析(GLS / GCS / GRS,Feature Tracking)。

**MVP 与 Siemens Cardiac 区别**:

- 字段命名差异:Vitrea 用 `CalciumVolume`(mm³) 而 Siemens 用 `AgatstonScore`;
- UI 风格:Vitrea 偏白底明亮,Siemens syngo.CT Cardio 偏暗;
- 默认阈值:Vitrea 默认钙化阈值 130 HU 体积,Siemens 默认 130 HU 面积加权。

## §6 与现有 RIS 的集成

### 6.1 检查 (Exam) 模块

- **触发 Workspace**: 当 `Exam.modality === 'CT' || 'MR'`,且 `Exam.bodyPart in [胸部, 腹部, 头颅, 心脏, 肝脏, 骨骼]`,在检查详情页显示"在 Vitrea 中打开"按钮;
- **触发 Cardiac**: 当 `Exam.modality in [CT, MR] && Exam.bodyPart === '心脏'`,显示"打开 Cardiac Suite"按钮;
- **触发 Fusion**: 当同一患者存在多模态检查(CT + PET / CT + MR / MR + MR),且时间间隔 ≤ 30 天,在检查对比页提示"是否融合";
- **触发 3D 打印**: 当 `Exam.modality === 'CT'`,显示"3D 打印"按钮(供骨科 / 心外科 / 颌面外科医师使用);
- **触发 Cloud**: 当 `Exam.status === 'signed'`,显示"上传到云"按钮。

### 6.2 报告 (Report) 模块

- **3D 截图嵌入**: Vitrea VR 截图支持嵌入报告所见部分(base64 内嵌);
- **钙化评分回写**: CTA 报告自动包含 Calcium Volume(mm³),与既有 Agatston 评分并存,字段独立;
- **PI-RADS 评分回写**: 前列腺 MR 报告自动填充 PI-RADS v2.1;
- **瓣膜评估回写**: 心脏 CT 报告中瓣膜字段自动填充。

### 6.3 患者 (Patient) 模块

- **3D 打印订单**: 患者详情显示 3D 打印订单状态(queued / slicing / printing / completed);
- **云端共享历史**: 患者详情显示该患者的历史云端共享记录(查看次数 / 链接有效期)。

### 6.4 设备 (Device) 模块

- **Aquilion 设备档案**: 新增 `device.canonModel` 字段(Aquilion ONE / PRIME / Lightning / Vantage Galan / Cartesion Prime 等);
- **Vitrea 引擎映射**: 设备 → Vitrea 引擎映射(`device.vitreaEngineUrl`),由 Canon 现场工程师配置。

### 6.5 教学病例 (Teaching Files) 模块

- **3D 打印模型**: 教学病例可附加 STL 文件(教学使用);
- **Vitrea VR 预设**: 教学病例可保存 Vitrea 风格预设(教师预配置)。
