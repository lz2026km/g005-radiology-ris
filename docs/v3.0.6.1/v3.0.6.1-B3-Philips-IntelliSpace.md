## ⚠️ 范围声明 (Honest Scope — 比 B1/B2 更克制)

本文档描述 v3.0.6.1 交付的 **Philips IntelliSpace PACS / Portal** MVP 适配层。**与 B1 (GE) / B2 (Siemens) 相比, 本模块更克制**:

- 仅 5 个组件模块 (vs GE 8 / Siemens 7)
- 总升级点 200 (vs GE/Siemens 300)
- 多个子模块仅交付 **stub/占位 UI + 字段契约**, 不实现真实逻辑
- Tumor Tracking 仅交付数据展示, 不实现 AI 推理

**v3.0.6.1 不包含**:

- 真实 Philips IntelliSpace Portal Web 服务调用
- 真实 Philips DoseWise 剂量网关
- 真实 Philips CMR 42 心脏 MR 后处理
- 真实 Philips AI Manager 算法编排引擎
- 真实 Philips Vue Speech 语音报告

v3.0.6.1 仅交付:**前端 MVP 组件 + Mock 数据 + 字段契约 + 路由 + i18n**。多个模块处于 **"stub"** 状态, 实际逻辑需 v3.0.7+ 由 Gateway Adapter 完成。**生产部署需要客户侧提供 IntelliSpace License**。

**Stub 标识约定**: 在 API 契约字段上标注 `(stub)` 表示该字段值在 v3.0.6.1 由前端随机生成或固定 Mock, 真实环境需 Gateway Adapter 提供。

## 1. 概述与市场定位 (Overview & Market Position)

### 1.1 Philips 在中国市场的位置

| 产品线 | 定位 | 中国市场份额 |
|---|---|---|
| **IntelliSpace PACS (ISP)** | 放射主 PACS | ~10% |
| **IntelliSpace Portal (ISP Portal)** | 高级可视化 (CT/MR 3D) | 高端三甲 |
| **DoseWise** | 辐射剂量管理 | 强 (Philips 设备配套) |
| **CMR 42** | 心脏 MR 后处理 (Circle Cardiovascular Imaging 收购) | 心内 |
| **AI Manager** | 算法编排平台 (2022+) | 新装机 |
| **IntelliVue** | 监护 (非放射) | ICU/CCU |
| **Vue PACS** (旧) | 2015 前后产品 | 渐淘汰 |

**对 G005 RIS 的意义**:

Philips 在中国:

1. **CT/MR 设备** iCT / Ingenia / Ambition / Achieva — 装机量前 5
2. **IntelliSpace PACS** 是主要 PACS 竞品
3. **IntelliSpace Portal** 是高级后处理标配
4. **CMR 42** 是心脏 MR 专科软件
5. **DoseWise** 是飞利浦剂量管理 (与 GE DoseWatch 对标)

**v3.0.6.1 范围克制的原因**:

- Philips IntelliSpace Portal 的 API 文档较少, 实际集成需要 Philips Professional Services 介入
- CMR 42 是付费第三方, 客户购买率不到 50%
- DoseWise 与 GE DoseWatch 功能重叠, 客户往往只部署一个
- AI Manager 与 GE Edison / Siemens AI-Rad 高度竞争, 客户选型分散

故 v3.0.6.1 仅交付 **5 模块 / 200 点** 的 MVP, 重点在**字段契约对齐 + UI 占位 + i18n**, 真实集成推后到 v3.0.7+。

6. **i18n 键**: stub 相关文案独立 i18n key (`pacsPhilips.stub.banner`)
7. **代码注释**: 所有 stub 模块文件头部注释明确标注 STUB

### 7.3 实施前已知风险

1. **CMR 42 完全依赖 Philips Professional Services** — 客户需购买服务包
2. **AI Manager 真实 License** — 需要 Philips 算法市场账户
