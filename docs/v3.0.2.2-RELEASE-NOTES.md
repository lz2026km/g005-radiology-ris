# v3.0.2.2 Release Notes

**发布日期**:2026-06-09
**Git tag**: `v3.0.2.2`
**代号**:`Expansion-June-2026-Q2`
**类型**:前端 + 后端扩充补丁

## 概述

v3.0.2.2 在 v3.0.2.1 基础上进行**功能性扩充**,新增:
- **8 个前端组件** — 报告质量、智能模板、双签、危急值实时、患者时间轴、MPR、剂量追踪、工作流引擎
- **3 个后端模块 / 16 端点 + 1 WS gateway** — ReportsQuality + DicomWeb + Notifications
- **3 个 Prisma model** — ReportQualityScore / DicomInstance / Notification
- **3 个 i18n 命名空间** — v3quality / v3archive / v3cosign

## ✨ 前端新组件 (8 件)

### 报告质量子系统(3 件)
1. **ReportQualityScore** — 8 维度评分(结构化/术语/RADS/清晰度/长度/黑名单/危急/审核)
2. **ReportTemplatedGenerator** — 智能模板推荐(基于 6 因子加权)
3. **ReportCoSignPanel** — 双签工作流(5 状态机 + SHA-256 签名)

### 危急值 + 患者子系统(2 件)
4. **CriticalValueAcknowledgment** — WebSocket 实时确认
5. **PatientTimeline** — 患者全院就诊时间轴(8 事件类型过滤)

### DICOM + 检查 + 工作流子系统(3 件)
6. **DicomMprViewer** — 三平面 MPR 重建(轴/矢/冠 + 同步窗位)
7. **ExamDoseTracker** — 辐射剂量追踪(CTDIvol / DLP / DRL 对比 / 模态分布)
8. **WorkflowsEngine** — 临床工作流引擎(6 节点类型)

## 🔧 后端新模块 (3 模块 / 16 端点)

### ReportsQualityModule(5 端点)
- `GET /reports/quality/rules` — 评分规则
- `POST /reports/quality/evaluate` — 评估
- `GET /reports/quality/history/:reportId` — 历史
- `GET /reports/quality/trend/:reportId` — 趋势
- `POST /reports/quality/re-evaluate/:reportId` — 重评

### DicomWebModule(7 端点)
- `GET /dicom-web/capabilities` — 能力(3 transfer syntaxes)
- `GET /dicom-web/studies` — QIDO-RS 搜索
- `GET /dicom-web/studies/:study/series` — Series
- `GET /dicom-web/studies/:study/instances` — Instances
- `GET /dicom-web/studies/:study/series/:series/instances/:sop` — WADO-RS Retrieve
- `GET /dicom-web/studies/:study/series/:series/instances/:sop/metadata` — 元数据
- `POST /dicom-web/studies/:study` — STOW-RS Store

### NotificationsModule(5 端点 + WS)
- `GET /notifications/unread/:userId` — 未读数
- `GET /notifications/history/:userId` — 历史
- `POST /notifications/read/:id` — 标记已读
- `POST /notifications` — 创建
- `POST /notifications/broadcast` — 批量广播
- `NotificationsGateway.subscribe(userId, callback)` — WebSocket 订阅

## 🐛 已知限制

### v3.0.2.2 范围内
- WebSocket Gateway 简化为 EventEmitter(未集成 @nestjs/websockets)
- DICOMweb 元数据仅返回 DICOM JSON(未实现 PS 3.18 XML 选项)
- 评分规则暂不持久化到 DB(计算结果即时返回)
- 通知广播无重试/重发机制

### 沿用 v3.0.1-2.1
- 多项预存在 TS 错误(非本版本引入)
- a11y test 部分页面违规(预存在)
