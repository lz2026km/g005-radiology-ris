## 3. 核心能力

### 3.1 模板设计器

**三栏布局**：
- **左栏：字段库**（14 种字段类型，4 大分组）
  - 基础字段：文本 / 数值 / 日期 / 布尔
  - 选择字段：单选 / 多选 / 评分
  - 测量字段：长度(mm) / 面积(mm²) / 体积(cm³)
  - 特殊字段：图像引用 / 标注 / 公式 / 短语
- **中栏：画布**（章节 + 字段拖放）
  - 章节可增删改色
  - 拖拽即添加
  - 选中高亮
- **右栏：属性面板**
  - 显示标签 / 字段键名 / 数据类型 / 章节 / 单位 / 必填
  - 数值范围校验（min/max）
  - 占位提示 / 关联分类 / 依赖字段 / 描述说明
  - 选项配置（label:value 多行）

**元数据栏**：
- 名称 / 编码 / 设备 / 部位 / 范围（全院/科室/个人）/ 性别 / 年龄区间

**预览模式**：实时切换编辑/预览，预览画布模拟报告排版

**快捷操作**：克隆 / 全屏 / 编辑 / 删除

## 5. 用户视角演示路径

### 路径 1：设计新模板
1. 打开 `/template-management` → 点击"可视化设计器 (R2)"
2. 默认加载（或新建模板）
3. 左栏拖拽"长度测量"到中栏"检查所见"章节
4. 字段出现在画布中，选中
5. 右栏修改显示标签="长径"、单位="mm"、必填=true
6. 顶部预览按钮查看报告样式
7. 保存

### 路径 2：克隆现有模板
1. 打开 `/template-inheritance`
2. 左侧树选中"胸部CT平扫+增强"
3. 右侧显示父模板（根）
4. 点击"克隆" → 自动创建子模板
5. 跳转到设计器进行定制

### 路径 3：浏览分类
1. 打开 `/template-category`
2. 树视图：点击"CT → 胸部 → 平扫"
3. 右侧显示该分类下 2 个模板
4. 切换"平铺"视图
5. 搜索"心脏"
