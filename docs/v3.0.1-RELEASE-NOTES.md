## 2. 升级指南

### 2.1 从 v3.0.0 升级到 v3.0.1

```bash
git pull origin main
git checkout v3.0.1
pnpm install
pnpm dev
```

**破坏性变更**:**无**
- App.tsx 内部重构,所有路由保持不变
- i18n 命名空间新增,旧 key 全部保留(向后兼容)
- 后端**新增**模块,不影响前端 MSW 离线模式

### 2.2 数据库迁移

```bash
cd backend
pnpm install
docker compose up -d postgres
pnpm prisma:migrate
pnpm prisma:seed
pnpm start:dev
```

种子数据:
- 5 角色用户 (admin/director_li/doctor_wang/doctor_zhang/tech_liu,密码 `admin123` / `pass1234`)
- 3 设备 (CT/MR/DR)
- 3 患者
- 5 检查 + 5 报告 (1 已签发 / 1 审核中 / 3 书写中)
- 5 危急值 (2 危急 / 3 高危)
- 5 预约
- 5 RADS 模板
