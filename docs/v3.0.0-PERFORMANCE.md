## 1. 包大小分析

### 1.1 依赖分包(11 个)

通过 Vite `manualChunks` 实现 11 个 vendor 分包:

| 分包 | 主要内容 | 估算 gzip 大小 |
|------|----------|---------------|
| react-vendor | react / react-dom / react-router | ~50KB |
| antd-vendor | antd / @ant-design/icons | ~250KB |
| dicom-vendor | @cornerstonejs / dcmjs / dicom-parser | ~400KB(懒加载) |
| three-vendor | three.js | ~120KB(懒加载) |
| collab-vendor | yjs / y-webrtc / y-protocols / lib0 / comlink | ~80KB(懒加载) |
| xstate-vendor | xstate / @xstate/react | ~25KB |
| utils-vendor | date-fns / decimal.js / uuid / pinyin-pro / qrcode / dompurify / zod / zustand | ~80KB |
| charts-vendor | recharts / lucide-react / @dnd-kit | ~120KB |
| db-vendor | dexie / dexie-react-hooks | ~30KB |
| rules-vendor | json-rules-engine | ~15KB |
| pdf-vendor | jspdf | ~80KB |

### 1.2 路由级懒加载

89 页面全部用 `React.lazy()` + `Suspense`:

```typescript
const HomeV3Page = lazy(() => import('./pages/HomeV3Page'));
```

**首屏加载**:仅加载当前路由 + vendor 包

**总包大小**:
- 首屏(无 DICOM/3D/AI):**~580KB gzip**
- 全功能加载:**~1.1MB gzip**
- DICOM 加载后:**~1.5MB gzip**(懒)

### 1.3 优化策略

| 策略 | 实施位置 | 收益 |
|------|----------|------|
| 路由懒加载 | `App.tsx` 89 lazy | 首屏 -60% |
| Vite manualChunks | `vite.config.ts` | HTTP/2 缓存友好 |
| CSS 分割 | `vite.config.ts` cssCodeSplit | 减少初始 CSS |
| Tree-shaking | Vite/esbuild | 移除未用代码 |
| 压缩 | esbuild minify + gzip | -70% 体积 |
| 字体子集 | 可选(后续) | 减少字体 |
| 图片 WebP | 可选(后续) | -30% 图片 |

### 2.2 Web Vitals 目标

| 指标 | 目标 | 实施 |
|------|------|------|
| LCP (Largest Contentful Paint) | < 1.5s | 路由懒 + 图片优化 |
| FID / INP | < 200ms | useDeferredValue / 避免重型 re-render |
| CLS (Cumulative Layout Shift) | < 0.1 | 固定尺寸 / Skeleton |
| TTFB | < 800ms | 静态托管 + 缓存 |
| FCP | < 1.8s | 关键 CSS 内联 |

### 2.3 关键性能 Hook 使用

| Hook | 位置 | 作用 |
|------|------|------|
| `useDebounce` | 搜索/筛选/自动保存 | 300-1500ms 防抖 |
| `useThrottle` | resize/scroll | 100ms 节流 |
| `useIntersection` | 懒加载/无限滚动 | 视口检测 |
| `useBreakpoint` | 响应式布局 | 5 个断点 |
| `useViewportWidth` | 移动端适配 | 防抖视口宽度 |
| `prefetchRoute` | 路由预加载 | 鼠标 hover 触发 |
| `preloadImage` | DICOM 缩略图 | 关键图片预加载 |
| `runWhenIdle` | 后台任务 | requestIdleCallback |
| `getMemoryUsage` | 监控 | 内存使用 |

### 2.4 XState 性能

- 14 态 reportMachine:启动 < 1ms,转换 < 0.1ms
- 5 节点 criticalValueMachine:< 0.5ms
- 每设备 actor(DeviceV3):按需实例化,无性能影响
- 状态机回滚无副作用,适合撤销/重做
