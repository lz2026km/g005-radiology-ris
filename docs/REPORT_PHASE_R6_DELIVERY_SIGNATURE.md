## 3. 核心能力

### 3.1 报告导出中心

**8 种导出模板**：
- 标准报告 PDF（含图+签名+二维码+水印，A4，~850KB）
- 简化报告 PDF（仅结论，A5，~120KB）
- 科研用 PDF（完整 DICOM 图像+测量数据，~12MB）
- 医保专用 PDF（含 ICD-10 + DRG）
- 患者告知 PDF（通俗易懂）
- Word 可编辑（~2.3MB）
- DICOM SR（DICOM 结构化报告）
- HTML 网页版

**功能**：
- 多报告批量选择（Checkbox）
- 实时进度条 0-100%
- 格式过滤（PDF/Word/HTML/DICOM-SR）
- 模板规格对比

### 3.2 报告推送中心

**8 种推送渠道**：
- 微信（公众号/小程序）
- 短信（含链接）
- Email（PDF 附件）
- 站内（患者 App）
- DICOM（推到 PACS）
- 纸质打印
- 云盘（链接分享）
- 胶片打印

**KPI**：本月 156 / 成功率 95.5% / 阅读率 78.2% / 下载率 42.3%

**功能**：
- 渠道分布彩色卡片（8 渠道点击过滤）
- 批量推送 + 实时进度
- 失败重试按钮
- 阅读/下载统计

### 3.3 患者端 H5 门户

**手机模型预览**（280×560 暗色边框）：
- 4 个底部 Tab：首页 / 报告 / 影像 / 我的
- 首页：欢迎卡 + 报告列表 + 快速入口
- 报告：所见/诊断/建议 + PDF/影像/分享 3 按钮
- 影像：6 缩略图网格
- 我的：用户信息 + 5 设置项

**访问审计**：
- 访问令牌（如 `PT-2026-001-ABCDEF`）
- 二维码 URL
- 过期时间
- 设备指纹（iPhone-15-Pro-iOS-17.4）
- IP 历史记录
- 查看/下载/分享计数

### 3.4 CA 数字签名

**5 张证书**（4 有效 / 1 即将过期 / 1 已过期）：
- 4 张 RSA-SHA256（CFCA 颁发）
- 1 张 SM2-SM3（GMCA 颁发，国密）

**签名操作**：
- 实时进度条 0-100%
- 签名结果显示（算法+时间+签名值+证书链）
- 证书详情（ID+序列号+颁发机构+有效期+指纹+已签次数）
- 状态：有效 / 即将过期 / 已过期 / 已吊销

**证书链可视化**：
- 根 CA → 中间 CA → 用户证书
- 每级标注"✓ 已验证"

### 3.5 区块链存证

**5 条存证记录**（4 已确认 / 1 待确认）：
- 报告哈希 SHA-256
- 交易哈希
- 区块哈希
- Merkle 根
- 6+ 节点确认
- 联盟链名称（GMCA）

**验证流程**：
- "验证真伪" 按钮 → 2 秒模拟验证
- 通过结果显示：区块存在 + Merkle 匹配 + 哈希未篡改 + 签名有效

**区块结构可视化**：5 大字段（区块头/前一哈希/Merkle 根/时间戳/Nonce）

**区块浏览器跳转**：链接到 `https://chain.gmca.cn/block/182345`

## 5. 用户视角演示路径

### 路径 1：报告导出
1. 打开 `/report-export`
2. 左选"标准报告 PDF" → 右选 5 份报告
3. 点击"导出" → 进度 0-100%
4. 完成提示：5 份 × 850KB

### 路径 2：批量推送
1. 打开 `/report-delivery`
2. 顶部 8 渠道彩色卡片
3. 勾选多条 → 点击"批量推送"
4. 进度条 → 成功提示

### 路径 3：患者端 H5
1. 打开 `/patient-report-portal`
2. 左选 1 个访问授权
3. 右看手机模型（4 Tab 切换）
4. 详情：令牌+设备指纹+IP 历史

### 路径 4：CA 签名
1. 打开 `/ca-signature`
2. 左选"张明远（CFCA RSA）"
3. 右点"立即签名" → 进度
4. 签名结果显示：算法+签名值+证书链

### 路径 5：区块链验证
1. 打开 `/blockchain-proof`
2. 左选区块 #182345
3. 右显示 4 类哈希
4. 点"验证真伪" → 通过结果显示
