- **时间戳**统一 `2026-06-XX` 区间(与系统当前日期保持一致)
- **隐私合规**:即使前端 Mock,数据 schema 已考虑脱敏

### 6.14 ⭐ v2.1.0 新增:MSW Handlers

`src/services/mswHandlers.ts` 与 OpenAPI 一一对应,在 dev 模式下由 Service Worker 拦截:

```typescript
// 启用流程(伪代码)
if (import.meta.env.DEV) {
  const { worker } = await import('./mswHandlers');
  await worker.start({ onUnhandledRequest: 'bypass' });
}
```

**价值**:
- 前端代码与 OpenAPI 完全解耦
- 后端就绪后只需切换 baseURL
- 离线开发 / 演示不依赖后端
- 测试用例可重放(MSW 支持录制)
