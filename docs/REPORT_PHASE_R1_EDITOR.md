## 3. 核心能力

### 3.1 关键字纠错引擎

**8 大检测维度**：

| # | 类别 | 检测项 | 严重度 |
|---|---|---|---|
| 1 | 解剖方位 | 左右 / 上下 / 前后 / 内外 4 对 | warning/info |
| 2 | 阴/阳矛盾 | 未见-可见 / 阴性-阳性 / 正常-异常 / 明确-不明确 / 有-无 | error |
| 3 | 否定词歧义 | "未见" 应配合"明显"等修饰 | info |
| 4 | 标点规范 | 英文逗号/句号/冒号/连续感叹号/问号/半角括号 | warning/info |
| 5 | 标准格式 | CT 值缺 HU / 尺寸格式 / 体温写法 / 体重单位 | info |
| 6 | 病灶关键词 | 按 modality + bodyPart 自动检测 | warning/info |
| 7 | 危急值 | 关键提示词缺失 | warning |
| 8 | 意见完整性 | "考虑/提示/建议/诊断" 等判断词 | warning |

**评分系统**：错误 -20 / 警告 -8 / 提示 -2，0-100 分；≥ 80 分为通过。

### 3.2 富文本编辑器

**4 大工具栏组 + 医疗专用**：

- 文字格式：加粗 / 斜体 / 下划线 / 上下标
- 段落：H1 / H2 / 引用 / 正文 / 有序列表 / 无序列表
- 对齐：左 / 中 / 右
- 插入：链接 / 图像 / 代码
- **医疗专用**：插入测量值 / 征象 / 公式 / 化验
- **特殊符号下拉**：° / ± / ≤ / ≥ / α / β / γ / μg / mmHg / HU / m² / cm³ / ↑ / ↓ / → / ※

**快捷键**：Ctrl+B / Ctrl+I / Ctrl+U / Ctrl+S（保存） / Ctrl+Enter（提交） / Ctrl+M（测量）

**底部状态栏**：字数 / 检查得分 / 问题计数

### 3.3 结构化字段表单

**7 种数据类型**：

| 类型 | 渲染 | 适用 |
|---|---|---|
| text | Input | 检查所见 |
| number | Input[type=number] | 尺寸 / 计数 |
| enum | 单选胶囊 | Lung-RADS / BI-RADS / 狭窄程度 |
| multi-enum | 多选胶囊 | 斑块类型 / Lung-RADS 修饰符 |
| boolean | Checkbox | 是否发现病灶 |
| date | Input[type=date] | 随访日期 |
| scale | 1-5 评分 | 半定量评分 |

**高级特性**：
- 字段分组（按肺窗/纵隔/病灶/Lung-RADS 等）
- 依赖字段（`dependsOn`）— 选择"有病灶"后自动显示后续字段
- 必填校验 + 数值范围校验
- 字段标签显示分类徽标（BI-RADS / Lung-RADS / TI-RADS / CAD-RADS）

**6 大模板**：
1. 胸部 CT 平扫+增强（33 字段）
2. 头颅 CT 平扫（8 字段）
3. 乳腺钼靶 BI-RADS（11 字段）
4. 腹部 CT 平扫+增强（11 字段）
5. 冠脉 CTA CAD-RADS（7 字段）
6. 甲状腺超声 TI-RADS（7 字段）

### 3.4 病灶测量组件

**5 种测量类型**：

| 类型 | 单位 | 图标 | 颜色 |
|---|---|---|---|
| 长度 | mm | Ruler | 蓝 |
| 面积 | mm² | Calculator | 绿 |
| 体积 | cm³ | Move3D | 紫 |
| 角度 | ° | Crosshair | 黄 |
| 密度 | HU | Calculator | 青 |

**高级特性**：
- 按病灶编号自动分组
- 标记"RECIST 靶病灶"
- 自动汇总靶病灶总长度
- 一键删除

### 3.5 术语联想

- 30+ 常用报告短语
- 支持中文 / 拼音首字母 / 分类 / 同义词 4 维搜索
- 8 大分类：胸部 / 腹部 / 头颅 / 脊柱 / 四肢 / 乳腺 / 心脏 / 通用
- 点击即插入整段到正文

### 3.6 草稿自动保存

- 保存状态指示：未保存 / 保存中 / 已保存 + 时间
- 一键清空草稿

## 5. 用户视角演示路径

1. 打开 `/report-write-v2`
2. 默认加载待分配报告
3. 顶部查看患者信息 + 状态徽标 + 剩余时间
4. **富文本 Tab**：输入报告内容，工具栏加格式、插入特殊符号、查看底部关键字评分
5. **结构化字段 Tab**：选择"胸部CT"模板，依次填写肺窗所见、纵隔、病灶、Lung-RADS
6. **测量 Tab**：添加病灶尺寸、密度，标记 RECIST 靶病灶
7. 右侧模板：点击"胸部 CT 平扫模板"快速填充
8. 右侧术语：搜索"磨玻璃"联想插入
9. 右侧 AI 辅助：查看 5 大 AI 能力入口
10. Ctrl+S 保存 → 30s 自动保存 → Ctrl+Enter 提交
