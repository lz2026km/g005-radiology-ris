## 3. 核心能力

### 3.1 审核工作台

**三阶段状态机**：初审 → 终审 → 签发

**16 个任务样本**：
- 3 个待初审（其中 1 个超时）
- 3 个初审中（含 1 个超时）
- 3 个待终审（双审流程）
- 2 个终审中
- 3 个待签发（双审已完成）
- 2 个已驳回

**KPI 仪表盘**（顶部蓝紫渐变）：
- 今日审核 / 待初审 / 待终审 / 待签发 / 已超时 / 已驳回 / 按时率

**任务详情**：
- 三阶段流程指示（已完成/进行中/待开始）
- 报告内容只读预览
- 审核历史时间线（初审 + 终审意见）
- 审核操作面板（评分滑块 0-100 + 快捷评分 + 意见文本 + 通过/驳回按钮 + 提交）
- 驳回时意见必填

**超时预警**：超时高亮红色背景

### 3.2 修订管理

**修订链时间线**：
- 横向版本卡片流（v1.0 → v1.1）
- 动作徽标：初次发布 / 修订 / 补发 / 撤回
- 每版本显示作者 / 时间 / 发布状态 / 患者告知 / 修订原因
- 选中即设置左侧/右侧

**版本对比（Diff）**：
- 左右版本下拉切换
- 字段切换（所见 / 诊断 / 意见）
- Diff 面板：左侧（红底） / 右侧（绿底）
- 合并视图：红=删除（删除线）/ 绿=新增 / 黑=相同
- 修订变更列表：每个字段的 before/after 块

**4 个版本动作**：
- 初次发布：蓝
- 修订：黄
- 补发：紫
- 撤回：红

**操作按钮**：预览终版 / 通知患者 / 撤回报告

### 3.3 多人协同

**3 列布局**：
- 左：报告正文（实时编辑区 + 模拟光标 + 模拟选区高亮 + 同步状态）
- 中：评论批注（输入框 + @ 提醒 + 回复 + 解决）
- 右：实时活动流（9 状态类型 / 用户头像 / 详情 / 时间）

**在线用户**（顶部蓝紫渐变）：
- 6 个模拟用户（3 在线 + 1 离开 + 2 离线）
- 头像 + 姓名 + 状态徽标
- 实时显示在当前报告的协同者

**协同功能**：
- 光标位置实时显示（每 100ms 模拟微移）
- 选区高亮
- @ 提醒（评论中 @ 用户 + 头像快捷按钮）
- 嵌套回复（parentId）
- 解决/取消解决
- 显示/隐藏已解决

**7 种活动类型**：
- join / leave / edit / comment / select / mention / save

### 路径 1：审核一份新报告
1. 打开 `/report-review`
2. 查看顶部 KPI：今日 16 个 / 待初审 3 / 待终审 3

6. 点击"通过" → "提交初审"
7. 任务进入"待终审"分组
