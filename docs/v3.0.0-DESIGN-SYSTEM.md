## 1. 设计原则

1. **浅色优先**:医疗场景对可读性要求高
2. **暗色支持**:夜间值班 / 长时间使用
3. **WCAG 2.1 AA**:对比度 / 焦点环 / ARIA
4. **antd 5 对齐**:复用 ConfigProvider token
5. **i18n 优先**:所有文案支持中英

### 4.2 反馈交互

```typescript
import { useToast, useConfirm } from '@components/antd';

function SaveButton({ onSave }: { onSave: () => Promise<void> }) {
  const toast = useToast();
  const { confirm } = useConfirm();

  const handleClick = async () => {
    confirm.submit('当前报告', async () => {
      try {
        await onSave();
        toast.saved();
      } catch {
        toast.failed();
      }
    });
  };

  return <Button onClick={handleClick}>保存并提交</Button>;
}
```
