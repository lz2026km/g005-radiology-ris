# v3.0.2 Release Notes

**发布日期**:2026-06-09
**Git tag**: `v3.0.2`
**代号**:`Deep-Reports-2026-Q2`

## 🎯 核心主题:报告系统深度重构(DICOM SR + AI 报告)

v3.0.2 在 v3.0.1「十大 PACS 对标」基础上,聚焦于**报告子系统深度重构**,
对标 飞利浦 IntelliSpace / 西门子 IKM / GE Centricity 等顶级 PACS,
将报告从「自由文本」升级为「结构化 + AI 辅助 + 临床决策支持」。

## ✨ 新增 28 个组件(W1-W5 共 5 周,6 周总计划 100% 完成)

### 报告子系统 (18 件,4 周)

**W1 报告编辑器 v3.0.2(5 件)**
- `StructuredFieldEditor` — 结构化字段编辑器(BI/LI/TI/PI/CAD-RADS 5 大 RADS + 自定义)
- `MacroEngine` — 沙箱表达式引擎(`{{patient.age > 18 && ...}}` 递归下降解析)
- `MultiModalityPanel` — 多模态影像参考(CT/MR/PET 跨模态链接)
- `RequiredFieldGuard` — 必填字段守门(required + length + range + blacklist)
- `WordStyleEditor` — 报告编辑器重写为结构化混合(集成上述 4 件)

**W2 报告模板子系统(4 件)**
- `TemplatePreviewDiff` — 模板预览 + 行级 LCS 差异对比
- `TemplateInheritanceManager` — 模板继承链管理(树 + 链视图 + CRUD)
- `TemplateDesignerCanvas` — 模板可视化设计(7 字段类型拖拽)
- `TemplateCategoryTree` — 模板分类树(拖拽重分类 + 搜索)
- + `data/reportTemplates.ts` 30 个临床模板(CT 8 / MR 6 / DR 4 / US 3 / MG 2 / DSA 2 / 危急值 5)

**W3 校验/AI 引擎(5 件)**
- `PhraseBankPro` — 100+ 短语库(AI 推荐 + 模态/部位过滤 + 频次排序)
- `AIReportReview` — AI 复审(必填/冲突/黑名单/格式/长度 5 类)
- `KeywordHighlight` — 报告内联关键字高亮(ICD-10/RadLex/RADS/解剖/危急值)
- `InlineTermLookup` — 编辑器内联 ICD-10 + RadLex 检索
- `VoiceDictationPro` — 真实 Web Speech API 语音录入(中英文 + 医学词库纠正 + 自动标点)

**W4 报告生命周期(4 件)**
- `ReportReviewCenter` — 审核工作台(待审核/危急值/通过/退回 4 统计)
- `ReportRevisionHistory` — 修订历史(时间轴 + 版本对比 + 恢复)
- `ReportAuditChain` — 审计链(SHA-256 链式哈希 + 完整性校验 + JSON 导出)
- `SimilarCaseRecall` — 相似病例检索(Jaccard 相似度 + RADS 加权 + 3 维度排序)
- `ReportDicomSRExport` — **DICOM SR TID 1500 完整(2B-full 决策)**
  - 树形 ContentItem/ContentSequence
  - 8 种 ValueType(TEXT/NUM/DATETIME/CODE/CONTAINER/IMAGE/COMPOSITE/UIDREF)
  - DCMR 编码 + UCUM 单位(22 个)
  - 5 种关系(CONTAINS/INFERRED_FROM/SELECTED_FROM/HAS_OBS_CONTEXT/HAS_ACQ_CONTEXT)
  - 图像引用(ReferencedImageSequence)
  - JSON / XML / .dcm 序列化
  - SR Document General/Specific/PatientStudy 模块
  - Verification Flag + SOP Instance UID
