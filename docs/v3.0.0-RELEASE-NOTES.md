## 🆕 新增能力

### 1. 报告子系统 14 态状态机

- `reportMachine` 14 态:pendingAssignment → assigned → writing → submitted → reviewing → reviewed → signing → signed → published + amending/amended/withdrawn/rejected/archived
- 报告列表/书写/审核 3 个 V3 页面完整驱动
- CA 签名集成 / Merkle 审计链

### 2. 危急值子系统 5 节点

- `criticalValueMachine`:found → notified → acknowledged → resolving → resolved + escalated / cancelled
- 国家卫健委 2024 版 15 类目录
- 5 节点进度条 + 时间线展示
- 通知方法:phone / sms / system / email / wechat

### 3. 设备子系统 5 态

- `deviceMachine`:idle / inUse / maintenance / broken / offline
- 每设备一个 XState actor(DeviceV3Page)
- 设备效率 + 故障 + 维护完整流程

### 4. 预约子系统 5 态

- `appointmentMachine`:scheduled / checkedIn / completed / cancelled / noShow
- 日历视图 + 列表视图
- 7 模拟预约数据

### 5. 协同编辑状态机

- `collaborationMachine`:disconnected / connecting / connected / syncing / error
- Yjs CRDT + y-webrtc P2P

### 6. 设计系统(200+ Tokens)

- 暗色模式支持

## 🚀 升级指南(v2.1.0 → v3.0.0)

### 1. 升级依赖

```bash
# 已有依赖保持
# 新增 12 个依赖:
pnpm add antd@^5.21.6 @ant-design/icons@^5.5.1 i18next@^23.16.4 \
  react-i18next@^15.1.1 @xstate/react@^5.0.0 @sentry/react@^8.40.0 \
  web-vitals@^4.2.4 zod@^3.23.8 zustand@^5.0.1

pnpm add -D @axe-core/react@^4.10.0 @playwright/test@^1.49.0 \
  @lhci/cli@^0.14.0 openapi-msw@^2.0.0 i18next-scanner@^4.6.0
```

### 2. 路由迁移

```typescript
// 旧:指向 v0.x 页面
<Route path="/worklist" element={<WorklistPage />} />

// 新:指向 V3 页面
<Route path="/worklist" element={<WorklistV3Page />} />
```

### 3. i18n 迁移

```typescript
// 旧:自研 useTranslation
import { useTranslation } from '@/i18n';

// 新:i18next
import { useTranslation } from 'react-i18next';
```

### 4. XState 使用

```typescript
import { useMachine } from '@xstate/react';
import { reportMachine } from '@machines/reportMachine';

const [state, send] = useMachine(reportMachine, {
  input: { reportId, patientId, radiologistId },
});
```

### 5. 设计系统

```typescript
// 旧:内联 style
<div style={{ padding: 16, background: '#1e40af' }}>

// 新:用 Token
<div style={{ padding: 'var(--space-4)', background: 'var(--color-primary-700)' }}>
```

### 6. 业务组件

```typescript
// 旧:直接用 antd
import { Button, message, Modal } from 'antd';

// 新:用业务封装
import { AppModal, useToast, useConfirm } from '@components/antd';
```
