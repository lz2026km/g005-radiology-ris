## 1. 系统概述

### 1.1 系统简介

G005 放射科信息管理系统（Radiology Information System，简称RIS）是一套专为放射科设计的综合性临床信息管理平台。系统涵盖患者管理、检查预约、图像采集、报告书写、审核发布、胶片打印、AI辅助诊断、质量控制、设备管理、数据统计等放射科核心业务，实现了放射诊疗全流程的数字化、规范化管理。

本系统对标国内领先的放射科信息系统标准，适用于三级甲等医院放射科的日常运营管理。

### 1.2 主要功能模块

系统包含14个子系统，共计53个功能页面：

| 序号 | 子系统名称 | 功能页面数 | 主要功能 |
|------|------------|------------|----------|

| 2 | 患者管理 | 5个 | 患者管理、检查预约、预约管理、排队叫号、随访管理 |
| 3 | 报告管理 | 4个 | 报告列表、书写报告、危急值管理、会诊管理 |

### 1.3 系统特点

#### 1.3.1 全流程覆盖
从患者预约、检查执行、图像采集到报告审核发布，系统覆盖放射诊疗全流程，各环节数据互通互联，告别信息孤岛。

#### 1.3.2 实时数据监控
首页概览实时展示今日检查数量、报告数量、危急值数量、设备状态等关键指标，科室运营状态一目了然。

#### 1.3.3 智能预警机制
系统具备危急值预警、设备效率预警、报告超时预警、耗材不足预警等多维度预警功能，提前发现风险点。

#### 1.3.4 规范化诊疗流程
系统内置标准化的检查项目和报告模板，支持自定义模板配置，保证诊疗行为的规范化、标准化。

#### 1.3.5 AI辅助诊断
集成AI影像质控和AI结构化报告功能，辅助医生快速完成影像质控和报告书写，提升工作效率。

### 1.4 适用检查类型

系统支持以下放射检查类型的全流程管理：

| 检查类型 | 典型项目 | 说明 |
|----------|----------|------|
| CT | 全身CT、头部CT、胸部CT、腹部CT | 电子计算机断层扫描 |
| MR / MRI | 头部MRI、脊柱MRI、关节MRI | 磁共振成像 |
| DR / X线 | 胸部正侧位、骨关节、腹部立卧位 | 数字X线摄影 |
| DSA | 心血管DSA、神经血管DSA | 数字减影血管造影 |
| 乳腺钼靶 | 乳腺钼靶摄影 | 乳腺专用X线检查 |

### 1.5 硬件设备支持

系统支持与以下放射设备的数据对接：

- CT设备（GE Revolution CT、西门子Force CT等）
- MRI设备（GE Premier 3.0T、西门子Vida 3.0T等）
- DR设备（GE Definium系列、岛津Flexavision等）
- DSA设备（西门子Artis Pheno、GE IGS 7系列等）
- 乳腺钼靶设备（Hologic Selenia、GE Senographe系列等）
- PACS图像存储与传输系统
- 胶片打印机（DICOM打印）

## 3. 14个子系统53个功能页面详细介绍

### 子系统一：工作台

#### 3.1 首页概览页面（/）

**页面路径**：侧边栏 → 首页概览

**页面功能**：首页概览是放射科日常工作的指挥中心。系统实时展示今日检查数量、报告数量、待审核数量、危急值数量、设备状态等关键指标，帮助科室管理者和医生快速掌握科室运行状态。

**主要功能**：

1. **今日关键指标**
   - 今日检查总数：当日所有检查数量统计
   - 待审核报告：等待上级医师审核的报告数量
   - 危急值报告：当日含危急值的报告数量
   - 阳性结果：当日阳性检出数量和阳性率

2. **快捷操作入口**
   - 批量审核：支持多份报告批量审核
   - 新建报告：快速创建新报告
   - 危急值报告：快速筛选危急值报告
   - 阳性结果：快速筛选阳性结果报告

3. **搜索功能**
   - 支持按患者姓名、检查号、报告ID、Accession号搜索
   - 支持按设备类型筛选：CT、MR、DR、DSA、乳腺钼靶
   - 支持按报告状态筛选：待审核、已审核、已发布、已修改
   - 支持按报告医生和审核医生筛选
   - 支持日期范围筛选

4. **报告质量评分**
   - 展示整体报告质量评分（百分制）
   - 实时更新

**首页数据说明**：

| 指标 | 说明 | 示例 |
|------|------|------|
| 今日检查总数 | 当日全部检查数量 | 200 |
| 待审核报告 | 等待审核的报告数量 | 40 |
| 危急值报告 | 含危急值的报告数量 | 75 |
| 阳性结果 | 阳性检出数量及占比 | 200（100%） |

#### 3.2 检查工作列表页面（/worklist）

**页面路径**：侧边栏 → 工作台 → 检查工作列表

**页面功能**：检查工作列表是放射科技师和护士的每日工作入口。系统根据当日预约自动生成检查工作清单，支持按检查类型、设备、状态等多维度筛选，帮助工作人员高效完成每日检查任务。

**主要功能**：

1. **今日检查清单**
   - 自动显示当日所有预约检查
   - 按检查时间排序
   - 实时更新检查状态

2. **状态筛选**
   - 待执行：等待执行的检查
   - 执行中：正在进行的检查
   - 已完成：已完成采集的检查
   - 全部：显示所有

3. **类型筛选**
   - CT检查
   - MR检查
   - DR检查
   - DSA检查
   - 乳腺钼靶

4. **快速操作**
   - 刷新列表
   - 标记执行中
   - 标记已完成
   - 查看检查详情

#### 3.3 检查记录页面（/exams）

**页面路径**：侧边栏 → 工作台 → 检查记录

**页面功能**：检查记录页面展示所有历史检查的详细信息，包括检查参数设置、图像采集数据、影像所见描述等，是放射科检查数据管理的核心模块。

**主要功能**：

1. **检查记录查询**
   - 按患者姓名、检查类型、日期范围查询
   - 支持检查状态筛选
   - 支持设备类型筛选

2. **检查详情查看**
   - 检查基本信息：检查号、Patient ID、Accession号
   - 患者信息：姓名、性别、年龄、科室

### 子系统二：患者管理

#### 3.4 患者管理页面（/patients）

**页面路径**：侧边栏 → 患者管理 → 患者管理

**页面功能**：患者档案管理是放射科信息化管理的基础环节。系统建立完整的患者电子健康档案，记录患者基本信息、联系方式、过敏史、保险类型等关键数据，为后续检查预约、报告书写提供数据支撑。

**主要功能**：

1. **患者档案查询**
   - 支持按姓名、身份证号、手机号、就诊卡号等多条件查询
   - 搜索结果实时显示，快速定位目标患者

2. **患者档案展示**
   - 基本信息：姓名、性别、年龄、身份证号
   - 联系方式：手机号、家庭住址
   - 就诊信息：就诊卡号、医保类型、过敏史
   - 末次就诊日期

3. **新增患者**
   - 点击"新增患者"按钮
   - 填写患者基本信息
   - 保存后自动生成患者ID

4. **编辑患者信息**
   - 点击已有患者记录
   - 修改相关信息
   - 保存更新

#### 3.5 检查预约页面（/appointments）

**页面路径**：侧边栏 → 患者管理 → 检查预约

**页面功能**：检查预约是患者到放射科进行检查的第一步。系统提供检查项目预约功能，支持CT、MR、DR、DSA、乳腺钼靶等多种检查类型的预约登记，合理安排检查时间，优化患者就诊体验。

**主要功能**：

1. **预约登记**
   - 选择患者（从已有患者库选择或新建患者）
   - 选择检查类型：CT、MR、DR、DSA、乳腺钼靶
   - 选择检查项目：全身扫描、头部CT、胸部CT等
   - 设定预约日期和时间
   - 选择主诊医生
   - 备注特殊要求（如糖尿病史、禁食要求等）

2. **预约状态管理**
   - 待确认：新建预约，等待确认
   - 已确认：预约已确认，等待检查
   - 检查中：患者正在检查
   - 已完成：检查已完成
   - 已取消：预约已取消

3. **新建预约**
   - 点击"新建预约"按钮
   - 选择患者信息
   - 选择检查类型和具体项目
   - 设定预约日期和时间
   - 选择主诊医生
   - 如有特殊要求，在备注中说明
   - 点击"保存"完成预约

**数据字段说明**：

| 字段名 | 说明 | 示例 |
|--------|------|------|
| id | 预约唯一标识 | APT001 |
| patientId | 患者ID | P001 |
| patientName | 患者姓名 | 李建国 |
| examType | 检查类型 | CT |
| examItem | 检查项目 | 全身肿瘤筛查 |
| scheduledDate | 预约日期 | 2026-05-02 |
| scheduledTime | 预约时间 | 08:30 |
| status | 预约状态 | 已确认 |
| device | 检查设备 | CT-01 |
| doctor | 主诊医生 | 李明辉 |
| notes | 备注 | 糖尿病史 |

#### 3.7 排队叫号页面（/queue-call）

**页面路径**：侧边栏 → 患者管理 → 排队叫号

**页面功能**：排队叫号模块用于放射科检查室的患者排队管理。系统支持叫号、等待、重呼等操作，帮助维持检查室秩序，提升患者就诊体验。

**主要功能**：

1. **排队队列展示**

2. **叫号操作**
   - 点击"叫号"按钮呼叫下一位患者
   - 支持重呼（重复呼叫当前患者）
   - 支持跳过（跳过当前患者）

3. **检查状态更新**
   - 患者进入检查室后标记"检查中"
   - 检查完成后标记"已完成"

#### 3.8 随访管理页面（/follow-up）

**页面路径**：侧边栏 → 患者管理 → 随访管理

**页面功能**：随访管理用于跟踪患者的复查情况。系统记录患者的历次检查记录，支持设定随访提醒，帮助医生追踪患者病情变化和疗效评估。

**主要功能**：

1. **随访记录查询**
   - 按患者姓名、随访状态、日期范围查询
   - 支持按随访类型筛选

2. **随访状态管理**
   - 待随访：需要联系患者安排复查
   - 已随访：已完成随访
   - 失访：无法联系到患者

3. **新增随访**
   - 选择患者
   - 设定随访时间和方式
   - 记录随访内容和结果

#### 3.10 书写报告页面（/report-write）

**页面路径**：侧边栏 → 报告管理 → 书写报告

**页面功能**：书写报告页面是放射科医生书写诊断报告的工作平台。系统提供结构化报告模板，支持快捷键操作、AI填充、语音录入等功能，大幅提升报告书写效率。

**主要功能**：

1. **患者信息自动加载**
   - 从检查记录自动获取患者基本信息
   - 从检查设备自动获取采集参数

2. **报告内容编辑**
   - 临床指征：下拉选择或手动输入
   - 检查技术：自动填充，可修改
   - 影像所见：结构化输入，支持常用语快捷插入
   - 诊断结论：结构化输入，支持常用结论模板

3. **快捷键操作**
   - F2：语音录入
   - F5：AI填充报告
   - F7：提交报告
   - F12：显示/隐藏快捷工具栏

   - 草稿保存：临时保存报告，不提交审核

   - 一键发布（需审核权限）：直接发布报告

   - AI填充：根据检查图像自动填充报告内容
   - AI影像质控：自动检测图像质量和异常

**报告书写操作流程**：
1. 从报告列表点击"新建报告"或选择已有检查记录

4. 核对检查技术描述
5. 书写影像所见（可调用常用语模板）
6. 书写诊断结论（可调用常用结论模板）
7. 点击"保存"或"提交审核"
8. 如需审核，等待上级医师审核通过
9. 审核通过后，报告状态变更为"已发布"

## 4. 核心业务流程

### 4.1 检查全流程

```
患者预约 → 到检登记 → 检查执行 → 图像采集 → 报告书写 → 报告审核 → 报告发布
```

1. **预约登记**：患者在预约页面登记检查信息
2. **到检登记**：患者到达检查室，护士在排队叫号系统登记
3. **检查执行**：技师执行检查，采集图像
4. **图像采集**：图像自动上传至PACS
5. **报告书写**：医生书写诊断报告
6. **报告审核**：上级医师审核报告
7. **报告发布**：报告发布给临床和患者

### 4.2 危急值处理流程

```
发现危急值 → 确认危急值 → 通知临床 → 记录通知 → 跟踪处理
```

1. **发现危急值**：医生在书写报告时发现危急值
2. **确认危急值**：填写危急值类型和详情
3. **通知临床**：通过电话/SMS通知申请医生
4. **记录通知**：记录通知时间和结果
5. **跟踪处理**：跟踪患者后续诊疗情况

### 4.3 报告审核流程

```
新建报告（草稿） → 提交审核 → 待审核 → 审核通过 → 发布报告
                              ↓
                         审核拒绝 → 修改报告 → 重新提交
```

## 7. 常见问题

### 7.1 登录问题

**Q：忘记密码怎么办？**
A：请联系系统管理员（admin）重置密码。默认测试账号密码为123，正式环境请及时修改。

**Q：账号被锁定怎么办？**
A：请联系系统管理员解锁。连续输错5次密码后账号会自动锁定。

### 7.2 报告问题

**Q：报告无法提交怎么办？**
A：请检查：1）网络是否正常；2）必填字段是否完整；3）是否有权限。如仍无法解决，请联系技术支持。

**Q：如何修改已发布的报告？**
A：已发布的报告如需修改，需要管理员权限。请在报告列表找到对应报告，点击"修改"按钮，修改后重新提交审核和发布。

**Q：危急值通知失败怎么办？**
A：请确认通知对象手机号是否正确。如通知失败，请使用备用联系方式（电话直接拨打）并记录通知结果。

### 7.3 设备问题

**Q：设备离线怎么办？**
A：请检查：1）设备网络连接；2）设备电源；3）PACS连接配置。如无法解决，请联系设备工程师。

**Q：图像无法上传怎么办？**
A：请检查：1）网络连接；2）DICOM配置；3）存储空间。如仍无法解决，请联系技术支持。

### 7.4 数据问题

**Q：数据丢失怎么办？**
A：系统数据存储在本地LocalStorage，建议定期导出重要数据。如数据丢失，请联系技术支持尝试恢复。

**Q：如何导出数据？**
A：在各统计页面有"导出"按钮，支持Excel和PDF格式导出。批量导出请联系系统管理员。

### 7.5 其他问题

**Q：系统响应慢怎么办？**
A：请尝试：1）清理浏览器缓存（Ctrl+Shift+R）；2）检查网络；3）关闭不必要的后台程序。

**Q：打印格式不对怎么办？**
A：请在打印设置中选择正确的纸张大小和打印方向。建议使用系统推荐的打印模板。
