## 1. 系统概述与登录

### 1.1 系统简介

G005放射科信息管理系统（RIS）是专为放射科设计的综合性临床信息管理平台，参照GE Centricity、东软RIS、联影系统界面设计，适用于汉东省人民医院放射科。

**系统特点：**
- 全流程数字化管理：从检查登记、影像采集、报告书写、审核签发到报告发布全程覆盖
- 符合国家卫健委2024年版质控指标
- 支持AI辅助诊断和智能质控
- 区域影像协同，支持跨机构会诊
- 设备效率分析和成本效益评估

### 1.2 登录方式

**默认登录（演示模式）：**
系统默认以管理员身份自动登录，无需输入用户名密码。登录后自动进入首页概览。

| 字段 | 值 |
|------|------|
| 用户姓名 | 李明辉 |
| 用户角色 | 管理员 |
| 权限范围 | 全部功能 |
| 职称 | 主任医师 |

**登录后的顶部导航栏**显示当前用户信息，包含头像、姓名、职称。右侧有通知铃铛图标，点击可查看系统通知。

## 3. 检查工作列表操作手册

访问路径：左侧导航 → 工作台 → 检查工作列表

### 3.1 三大视图切换

页面顶部提供三种视图切换按钮：

**卡片视图（默认）**：
- 每个检查项目以卡片形式展示
- 卡片显示：患者姓名、检查类型、设备、优先级、时间、状态
- 适合快速浏览全貌

**列表视图**：
- 以紧凑表格形式展示所有检查项目
- 可显示更多列信息：登记号、患者姓名、性别、年龄、检查项目、设备、检查室、优先级、状态、时间、操作
- 适合批量操作和精确筛选

**日历视图**：
- 以日历形式展示检查安排
- 按日期分组显示每日检查量
- 可点击具体日期查看当天详细列表

### 3.2 筛选器操作（详细步骤）

**基础筛选**：
1. **日期范围**：点击日期选择器，选择起始和结束日期，默认显示今日
2. **设备类型**：下拉菜单选择CT/MR/DR/DSA/乳腺钼靶/胃肠造影，或"全部设备"
3. **患者类型**：下拉菜单选择门诊/住院/体检/急诊/全部
4. **优先级**：下拉菜单选择危重/紧急/急迫/普通/全部
5. **状态**：下拉菜单选择待检查/检查中/待报告/已完成/全部

**医生筛选**：
1. 点击"全部医生"下拉按钮
2. 弹出医生列表，显示医生姓名和职称
3. 点击选择特定医生，可按医生筛选其负责的检查

**重置筛选**：
- 点击"重置"按钮可恢复所有筛选条件为默认值

### 3.3 批量操作工具栏（重要功能）

当您勾选了1个或多个检查项目后，页面顶部出现批量操作工具栏：

**操作步骤**：
1. **勾选项目**：在列表/卡片左侧勾选框勾选，或点击卡片/行进行选择
2. **选择操作类型**：
   - 🔄 **批量修改优先级**：下拉选择新优先级（危重/紧急/急迫/普通），点击确认执行
   - 🏠 **批量分配检查室**：下拉选择检查室（CT室1、CT室2、MR室1、MR室2等），点击确认执行
   - 🖨️ **批量打印条码**：勾选后点击，自动生成并打印选中项目的条码标签
   - 📊 **批量导出Excel**：勾选后点击，自动导出选中项目的详细数据为Excel文件
3. **确认执行**：点击右侧绿色"确认执行"按钮
4. **清除选择**：点击"清除"按钮取消当前所有选择

**批量操作示例**：
- 场景：今日有多位急诊患者需优先处理
- 操作：筛选"急诊"类型 → 勾选全部 → 批量修改优先级为"紧急" → 批量分配检查室 → 确认执行

### 3.4 危急患者优先排序规则

系统自动按以下优先级排序显示检查项目：
1. 🟥 危重（红色标签，最优先）
2. 🟧 紧急（橙色标签）
3. 🟨 急迫（黄色标签）
4. ⚪ 普通（灰色标签）

### 3.5 检查状态说明

| 状态 | 含义 | 后续操作 |
|------|------|----------|
| 待检查 | 患者已登记，等待检查 | 技师执行检查 |
| 检查中 | 正在进行检查 | 技师完成检查 |
| 待报告 | 检查已完成，等待书写报告 | 医生书写报告 |
| 已完成 | 报告已完成 | 审核/发布 |
| 已发布 | 报告已发布至临床 | 归档 |

### 3.6 快捷操作

每个检查项目卡片/行右侧提供快捷操作按钮：
- 👁️ **查看**：打开检查详情
- ✏️ **书写**：直接跳转到报告书写页面
- 📋 **复制信息**：快速复制患者和检查信息

**适用检查**：胸部CT

2. 找到页面右侧的"Lung-RADS分类"面板

|------|------|----------|

| Lung-RADS 4A | 可疑恶性（≥8mm） | 进一步评估，PET-CT或活检 |

### 4.8 完整度检查

**操作步骤**：
1. 点击报告书写区域右下角的"完整度检查"按钮
2. 系统自动分析报告内容，给出完整度评分（0-100分）
3. 提示缺少的必要元素，如：
   - "缺少对【中线结构】的描述"
   - "缺少对【胸膜】的描述"
   - "建议补充诊断意见"
4. 根据提示补充缺失内容

### 4.9 保存和提交

**保存草稿**：
- 点击左上角"保存草稿"按钮，报告保存但不提交审核
- 建议每5分钟手动保存一次，防止数据丢失

**提交审核**：
- 点击右上角"提交审核"按钮
- 弹出确认对话框，显示即将提交的报告摘要
- 点击确认后，报告状态变为"待审核"，分配给审核医生

**打印预览**：
- 点击"打印预览"按钮
- 在新窗口/标签页显示打印格式的报告单
- 可直接按Ctrl+P打印或导出PDF

### 4.10 AI辅助诊断

**操作步骤**：
1. 书写报告过程中或完成后
2. 点击"AI辅助诊断"按钮
3. 系统自动分析影像数据（模拟）
4. 返回AI辅助建议，显示在报告右侧辅助面板：
   - 可能的诊断建议
   - 需要关注的异常区域
   - 鉴别诊断要点
5. 医生可根据AI建议决定是否采纳

## 12. 危急值管理与处理

### 12.1 危急值定义

**系统包含30个危急值项目**，涵盖以下类别：

### 12.2 危急值处理流程

```
发现危急值 → 确认危急值 → 通知临床 → 记录处理 → 随访追踪
     ↓           ↓           ↓           ↓           ↓
   技师/医生   上级医生    电话/短信    填写记录    确认临床处理
```

**详细操作步骤**：

**步骤1：发现危急值**
- 在报告书写过程中或AI辅助诊断时发现危急征象
- 系统自动标记并高亮显示危急值内容

**步骤2：确认危急值**
- 点击"确认危急值"按钮
- 选择危急值类型（从预置列表选择或自定义）
- 确认危急值描述内容

**步骤3：通知临床**
- 点击"通知临床"按钮
- 系统自动获取患者联系方式和主治医生
- 选择通知方式：
  - ☎️ 电话通知（记录通话内容）
  - 💬 短信通知（自动发送模板短信）
  - 📋 临床工作站推送
- 填写通知时间和接听人

**步骤4：记录处理**
- 在处理记录中填写：
  - 通知时间
  - 接听人姓名
  - 接听人职务
  - 临床反馈
  - 后续处理建议
- 点击"保存记录"完成

**步骤5：随访追踪**
- 在危急值追踪列表中
- 查看已通知但未确认临床处理的项目
- 必要时再次通知或升级处理

### 12.3 危急值列表视图

## 17. 常见问题与解决方案

### 17.1 登录问题

**问题1：无法打开登录页面**
- **可能原因**：服务器未启动或网络连接问题
- **解决方案**：
  1. 检查本地网络是否正常
  2. 确认服务器地址是否正确（http://8.137.71.217:5191）
  3. 联系管理员确认服务器状态

**问题2：登录后页面显示空白**
- **可能原因**：浏览器缓存过期或JavaScript被禁用
- **解决方案**：
  1. 尝试按F5刷新页面
  2. 清除浏览器缓存后重新访问
  3. 确保浏览器启用了JavaScript
  4. 尝试使用Chrome或Firefox浏览器

### 17.2 报告书写问题

**问题1：模板内容无法插入**
- **可能原因**：模板未正确加载或光标位置问题
- **解决方案**：
  1. 确认光标在"检查所见"或"诊断意见"文本框内
  2. 点击模板后等待1-2秒让系统响应
  3. 如仍不行，尝试手动复制粘贴模板内容

**问题2：报告保存失败**
- **可能原因**：网络中断或会话超时
- **解决方案**：
  1. 检查网络连接
  2. 点击"保存草稿"按钮重试
  3. 建议定期手动保存（Ctrl+S）
  4. 如持续失败，尝试重新登录后操作

**问题3：BI-RADS/Lung-RADS分类无法选择**
- **可能原因**：当前检查类型不适用该分类
- **解决方案**：
  1. BI-RADS分类仅适用于乳腺钼靶检查
  2. Lung-RADS分类仅适用于胸部CT检查
  3. 确认当前检查项目类型正确

### 17.3 DICOM浏览器问题

**问题1：影像加载缓慢**
- **可能原因**：网络带宽不足或影像文件过大
- **解决方案**：
  1. 检查网络连接
  2. 等待影像完全加载后再进行操作
  3. 关闭其他占用网络带宽的应用程序

**问题2：窗宽窗位调整无效果**
- **可能原因**：未选择正确的工具
- **解决方案**：
  1. 点击工具栏中的"窗宽窗位"工具（或按W键）
  2. 按住鼠标左键在影像上拖动调整
  3. 或直接点击预设窗值按钮

**问题3：标注工具无法使用**
- **可能原因**：标注功能未激活
- **解决方案**：
  1. 点击对应的标注工具按钮
  2. 在影像上点击或拖动创建标注
  3. 点击"删除标注"可移除不需要的标注

### 17.4 打印问题

**问题1：打印预览显示不完整**
- **可能原因**：浏览器打印设置问题
- **解决方案**：
  1. 在打印预览页面，点击"边距"设置为"无"
  2. 勾选"背景图形"选项
  3. 缩放设置为"适合页面"

**问题2：条码打印机无响应**
- **可能原因**：打印机连接问题或驱动未安装
- **解决方案**：
  1. 检查打印机电源和USB连接
  2. 在系统设置中确认打印机已正确配置
  3. 尝试打印测试页

### 17.5 数据统计问题

**问题1：统计数据不准确**
- **可能原因**：日期筛选范围问题或数据未同步
- **解决方案**：
  1. 检查筛选的日期范围是否正确
  2. 点击"刷新"按钮更新数据
  3. 如数据严重不符，联系管理员检查数据同步

**问题2：图表无法显示**
- **可能原因**：浏览器版本过低或JavaScript问题
- **解决方案**：
  1. 更新浏览器到最新版本
  2. 清除浏览器缓存
  3. 尝试使用Chrome浏览器

### 17.6 其他常见问题

**问题1：页面加载缓慢**
- **解决方案**：
  1. 清除浏览器缓存
  2. 关闭不必要的后台应用程序
  3. 尝试切换到有线网络

**问题2：部分功能按钮灰色不可点击**
- **可能原因**：当前用户权限不足
- **解决方案**：
  1. 确认登录用户角色是否具有该功能权限
  2. 联系管理员调整权限

**问题3：系统提示"会话已过期"**
- **解决方案**：
  1. 重新登录系统
  2. 建议定期操作以保持会话活跃
