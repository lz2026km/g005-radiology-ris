## 1. 系统概述与登录

### 1.1 系统简介

G005放射科信息管理系统（RIS）是专为放射科设计的综合性临床信息管理平台，参照GE Centricity、东软RIS、联影系统界面设计，适用于汉东省人民医院放射科。

**系统特点：**
- 全流程数字化管理
- 符合国家卫健委2024年版质控指标
- 支持AI辅助诊断
- 区域影像协同

### 1.2 登录方式

**默认登录（演示模式）：**
系统默认以管理员身份自动登录，无需输入用户名密码：

| 字段 | 值 |
|------|------|
| 用户姓名 | 李明辉 |
| 用户角色 | 管理员 |
| 权限范围 | 全部功能 |

登录后顶部导航栏显示当前用户信息，包含头像、姓名、职称。

### 3.3 筛选功能详解

#### 3.3.1 基础筛选

1. **搜索框**
   - 位置：筛选栏最左侧
   - 支持：患者姓名/Accession号/检查项目模糊搜索
   - 操作：输入关键词，下方列表实时过滤
   - 清除：点击搜索框右侧X按钮

2. **日期范围**
   - 开始日期：选择或输入开始日期
   - 结束日期：选择或输入结束日期
   - 快捷选项：今日/本周/本月/本季度

3. **高级筛选按钮**
   - 位置：筛选栏右侧
   - 点击展开：显示更多筛选条件
   - 收起：再次点击"收起"按钮

#### 3.3.2 高级筛选条件

1. **设备类型**（可多选）
   ```
   全部 | CT | MR | DR | DSA | 乳腺钼靶 | 胃肠造影
   ```
   - 点击选中/取消
   - 选中项显示蓝色背景

2. **患者类型**（可多选）
   ```
   门诊 | 住院 | 急诊 | 体检
   ```

3. **优先级**（可多选）
   ```
   普通（灰色）| 紧急（橙色）| 危重（红色）| 会诊（紫色）
   ```

4. **检查状态**（可多选）
   ```
   已登记 | 待检查 | 检查中 | 待报告 | 已报告 | 已发布 | 已取消
   ```

5. **执行医生**
   - 下拉选择
   - 选择"全部医生"显示所有

#### 3.3.3 筛选重置

点击"重置"按钮清除所有筛选条件，恢复默认显示

```
├── 系统自动弹出危急值确认对话框
└── 医生确认是否需要通知临床

第2步：标记危急值
├── 点击"危急值"按钮
├── 填写危急值描述
└── 选择通知方式（电话/短信/系统）

第3步：发送通知
├── 填写被通知人（临床医生）
├── 填写通知内容
├── 选择通知时间
└── 点击"发送通知"

├── 临床医生收到通知
├── 临床医生确认接收
└── 系统记录接收时间

第5步：处理完成
├── 临床处理危急值
├── 放射科确认处理结果
└ └── 记录处理时间和结果
```

**状态流转：**
```
发现 → 待通知 → 已通知 → 已接收 → 已处理
         ↓
      通知失败（可重试）
```

## 16. 常见问题与解决方案

### 16.1 登录问题

**问题1：页面一直加载中**
```
可能原因：网络连接问题
解决方案：
1. 检查网络是否正常
2. 刷新页面（按F3）
3. 清除浏览器缓存
4. 更换浏览器尝试
```

**问题2：提示"无权限访问"**
```
可能原因：当前角色无权访问该页面
解决方案：
1. 确认当前登录用户角色
2. 联系管理员开通权限
```

### 16.2 报告书写问题

**问题1：无法保存报告**
```
可能原因：必填项未填写
解决方案：
1. 检查所见描写是否填写
2. 检查诊断意见是否填写
3. 确保已选择检查项目
4. 点击保存按钮重试
```

**问题2：模板无法应用**
```
可能原因：模板与检查类型不匹配
解决方案：
1. 确认检查设备类型（CT/MR/DR等）
2. 选择对应类型的模板
3. 模板与检查类型需一致
```

**问题3：提交审核失败**
```
可能原因：报告未完成或超时
解决方案：
1. 检查报告完整度（需>80%）
2. 确认所有必填项已填写
3. 检查报告是否超时
4. 联系管理员确认审核流程
```

### 16.3 DICOM浏览问题

**问题1：影像加载缓慢**
```
可能原因：网络带宽不足或服务器负载高
解决方案：
1. 等待加载完成
2. 刷新页面重新加载
3. 联系管理员检查网络
```

**问题2：无法导入DICOM文件**
```
可能原因：文件格式不正确
解决方案：
1. 确认文件为标准DICOM格式
2. 检查文件是否损坏
3. 尝试重新导出DICOM文件
```

**问题3：窗宽窗位调整无效**
```
可能原因：操作方式不正确
解决方案：
1. 左键拖动图像进行调整
2. 或点击预设窗宽窗位快速切换
3. 点击"重置"恢复默认
```

### 16.4 设备问题

**问题1：设备状态显示不正确**
```
可能原因：状态同步延迟
解决方案：
1. 刷新页面
2. 等待1-2分钟自动更新
3. 联系管理员检查设备连接
```

**问题2：预约无法选择时间段**
```
可能原因：该时间段已满
解决方案：
1. 选择其他时间段
2. 或选择其他设备
3. 查看设备预约规则设置
```

### 16.5 系统性能问题

**问题1：页面响应缓慢**
```
解决方案：
1. 清除浏览器缓存
2. 关闭不必要的后台程序
3. 建议使用Chrome浏览器
4. 联系管理员检查服务器状态
```

**问题2：数据丢失**
```
解决方案：
1. 检查网络是否稳定
2. 定期保存报告草稿
3. 刷新页面查看数据是否恢复
4. 联系管理员查询备份数据
```
