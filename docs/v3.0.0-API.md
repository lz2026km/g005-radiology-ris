## 1. 通用规范

### 1.1 响应格式

```json
{
  "success": true,
  "data": { ... },
  "meta": {
    "page": 1,
    "pageSize": 20,
    "total": 150,
    "totalPages": 8
  },
  "message": "操作成功"
}
```

### 1.2 错误格式

```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "输入校验失败",
    "details": [
      { "field": "patientName", "message": "患者姓名不能为空" }
    ]
  }
}
```

错误码:`VALIDATION_ERROR / UNAUTHORIZED / FORBIDDEN / NOT_FOUND / CONFLICT / INTERNAL_ERROR`

### 1.3 分页参数

```
?page=1&pageSize=20&sort=createdAt&order=desc
```

## 2. 报告接口(11 个)

### 2.1 列表查询

```http
GET /api/v1/reports
```

参数:
- `status` - 报告状态(14 态枚举)
- `patientId` - 患者 ID
- `modality` - 设备类型
- `priority` - 优先级
- `dateFrom` / `dateTo` - 日期范围
- `page` / `pageSize` - 分页

### 2.2 详情

```http
GET /api/v1/reports/{id}
GET /api/v1/reports/{reportId}
```

### 2.3 创建 / 更新 / 删除

```http
POST   /api/v1/reports
PUT    /api/v1/reports/{id}
DELETE /api/v1/reports/{id}
```

### 2.4 流转

```http
POST /api/v1/reports/{id}/submit   # 提交审核
POST /api/v1/reports/{id}/review   # 审核
POST /api/v1/reports/{id}/sign     # CA 签名
POST /api/v1/reports/{id}/reject   # 驳回
POST /api/v1/reports/{id}/revise   # 修订
GET  /api/v1/reports/stats         # 统计
```

### 2.5 报告 14 态枚举

```
draft:        待分配 / 已分配 / 书写中
review:       已提交 / 初审中 / 初审通过 / 终审中 / 已审核
sign:         签发中 / 已签发
published:    已发布
special:      修订中 / 已修订 / 已撤回 / 已驳回 / 已归档
```
