## 1. 一句话商业模式

**G005 是面向三甲医院的"纯前端 + AI 增强"放射科信息系统,以订阅式 SaaS 降低医院信息化门槛,以 AI 增值服务(DeepSeek + RADS + 影像组学)实现差异化,12 周内完成商业化并向二级 / 医联体 / 三甲医院阶梯式销售。**

## 3. 价值主张

### 3.1 核心价值(对三甲医院)

> **"用 1/3 的价格,享受国产高端 PACS 的 80% 能力,加上 AI 增强和 6 个月内可上线"**

| 价值 | 对标 | G005 提供 |
|------|------|-----------|
| **AI 辅助诊断** | 西门子 AI-Rad / 联影 uAI | ✅ DeepSeek 8 类 Prompt + 11 套 RADS + 16 类(规划) |
| **危急值闭环** | 岱嘉 / 英飞达 | ✅ 国家卫健委 2024 版 15 类 + 5 节点 |
| **报告质量** | 西门子 / 飞利浦 | ✅ 14 态状态机 + 评分引擎 + 缺陷库 |
| **协同编辑** | 无 | ✅ Yjs CRDT + y-webrtc(2-5 人) |
| **CA 签名** | 全行业必备 | ✅ Web Crypto RSA-SHA256 + 证书链 |
| **区块链存证** | 西门子等高端 | ✅ Merkle Tree + 验证 |
| **RADS 自动化** | 西门子 | ✅ 11 套 RADS 完整数据 |
| **术语库** | 行业领先 | ✅ 1247 词 + 7 分类 + 4 大标准 |
| **移动端** | 锐科 / 岱嘉 | 🟡 规划中 W5-6 / W11-12 |
| **DICOM Pro** | 全行业 | ✅ MPR/MIP/VR/标注/伪彩 |

### 3.2 差异化优势(对竞品)

**1. AI 增强门槛低**
- 不需要部署 GPU 推理服务器(后端)+ 也不需要自训模型
- 复用 DeepSeek 通用大模型 + 8-16 类专业 Prompt
- 接入成本 = 0,试用 = 1 周

**2. 纯前端部署快**
- 不依赖医院 PACS / 后端
- 部署 = 静态文件 + CDN / 内网
- 上线时间 = 2 周(对比传统 3-6 月)

**3. 文档 / 培训完善**
- v2.1.0 4 分册 4500+ 行
- 5 个演示场景
- 培训手册 + 售前 PPT
- 客户可自学 80% 功能

**4. 价格优势**
- 订阅式 SaaS,初期投入低
- 50 万起 vs 联影 300 万 / 西门子 800 万
- 总拥有成本(TCO)5 年内低 60%+

## 5. 渠道策略

### 5.1 直销(60%)

- **销售团队**:3-5 名资深销售(医疗信息化背景)
- **目标客户**:三甲 / 区域影像中心
- **决策周期**:6-12 月
- **签约模式**:5 年长期合同

### 5.2 渠道合作(25%)

- **医疗集成商**:与卫宁 / 东软 / 创业等总包合作
- **设备厂商**:与联影 / GE / 西门子 / 飞利浦 OEM 集成
- **政府项目**:医联体 / 区域影像中心 / 县级医院项目
- **决策周期**:3-6 月
- **分润模式**:渠道 15-25%

### 5.3 互联网营销(10%)

- **官网 SEO**:"放射 PACS / RIS / 危急值 / 报告系统"关键词
- **行业媒体**:HC3i / 医谷 / 健康界 / 动脉网
- **学术会议**:中华放射学会 / 中国医学影像 AI 大会
- **目标客户**:民营 / 体检 / 宠物

### 5.4 战略合作(5%)

- **DeepSeek 战略合作**:API 价格 + 联合品牌
- **国家级实验室**:中科院 / 协和 / 301 医院合作
- **医疗 AI 公司**:推想 / 数坤 / 联影智能互补

## 8. 风险与缓解

| 风险 | 等级 | 缓解 |
|------|------|------|
| 销售周期 > 12 个月 | 高 | 先切入二级 / 医联体,快赢单;产品 Demo 化为销售加速器 |
| 价格战(联影 / 东软) | 高 | 强调"前端产品"差异 + AI 增强 + 订阅式低 TCO |
| 客户使用率低 | 中 | 客户成功体系 + 培训认证 + 季度回访 |
| 关键人员流失 | 中 | 股权激励 + 知识沉淀(Storybook / 文档) |
| 监管政策变化 | 中 | 紧密跟随卫健委 / 等保政策,合规前置 |
| 纯前端方案被质疑 | 中 | MSW 演示 + 集成服务包 + 透明技术栈 |
